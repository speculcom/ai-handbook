# 怎么读模型卡与系统卡（How to Read Model Cards and System Cards）

**这份指南解决什么**：模型卡讲「这个模型是什么、怎么用」，系统卡与部署安全页讲「上线前测过什么、还担心什么」。两份要分开读、对照读。

**怎么做**：
1. 先分清对象：模型卡面向使用者（用途、限制、评测口径、训练数据说明），系统卡或部署安全页面向风险关注者（测了哪些风险、结果如何、什么条件下继续推进）。
2. 看它测了什么、没测什么：只有能力评测、没有失效场景说明的文档，撑不起高风险用途；反过来只讲风险、不给可核对的口径也不行。
3. 版本与日期一起记：同一型号在不同批次的卡片上结果可能不同，引用时把版本号与发布日期写进你的记录。
4. 重点读「不适合做什么」那一栏：厂商写明的失败场景与拒答行为比宣传语可用；没有这一栏的卡片要打折看。
5. 对照自己的用途找缺口：你要跑的场景如果不在它的评测覆盖里，这个缺口要自己补测，不能靠外推补齐。
6. 举个例子（虚构需求）：输入是团队想用某个模型做医疗问答初稿 → 处理是把它的模型卡与系统卡并排读，列出「有没有医疗相关评测」「已知拒答与幻觉说明写在哪一栏」→ 结果判断是若两类文档都没覆盖该场景，结论写「卡片不足以支持此用途」→ 下一步是把该场景写进自己的评测样本，小范围试跑并留记录，再决定是否接入。

**出处**：模型卡的结构出自 Mitchell 等人的原始论文；卡片与安全页的实际形态看三家厂商的官方页面。例子里的医疗场景与判断结论是虚构需求，不代表任何厂商的卡片内容。
