# 怎么防提示注入（How to Guard Against Prompt Injection）

**这份指南解决什么**：提示注入是让外部内容劫持 AI 的攻击。这份指南讲怎么给 AI 工具设防线，让它不把网页里的话当命令。

**怎么做**：
1. 把外部内容当数据，不当指令：网页、文档、邮件里可能藏着「忽略之前的指令」。
2. 给最小权限：能读就只给读，能用一个目录就别给整个盘。
3. 不可逆操作留人工确认：删除、转账、对外发消息，先问人再执行。
4. 隔离会话：处理外部内容的会话，别和管密钥、管账户的会话混用。
5. 装工具前查它能碰什么：MCP server 的权限声明要先读。
6. 留执行日志：出问题时能回放它到底做了什么。

**出处**：OWASP 把提示注入列为 LLM 应用十大风险之首；本站抓取工具档案里也记录了这类攻击的具体形态（见下）。
