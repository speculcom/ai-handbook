# 通过一次评测就可以上线（Passing One Evaluation Is Enough to Ship）

**这份指南解决什么**：上线不是通过一场考试，而是一个需要被持续检查的状态。

**大家以为**：上线前把评测跑通一次，之后就可以不用管了。

**其实**：那一次通过只覆盖当时的版本组合：模型版本、提示、检索到的材料、用户问法与数据分布，任何一项变动都可能让结论失效。发布后要留抽检、监控与回滚路径，改动时复跑同一套样本。（虚构示例）输入是一次「只更换检索源、模型与提示都没变」的改动 → 处理是复跑同一套样本 → 结果判断看的是「引用是否命中现行文档」这一项口径 → 若该项通过率下降，下一步是重新做上线判断并给检索源加一条变更检查，而不是沿用旧一次的「已通过」。
