# 怎么用 AI 做翻译与本地化（[object Object]）

**这份指南解决什么**：翻译不是逐句替换，而是让目标语言读者觉得这句话本来就该这么说。

**怎么做**：
1. 先定目标：是给客户看的营销文案、给工程师看的规范，还是给监管看的合规文本；语域不同，译法不同。
2. 给术语表、品牌名、禁译词和示例句；没有术语表，模型会每次换一个译法。
3. 长文分段翻译并保留编号，方便回填和对照；不要一次性丢整本书。
4. 让模型标出「直译但别扭」和「意译但可能偏离」的句子，由人决定。
5. 本地化还要检查日期、货币、地址、称呼、颜色和宗教/文化禁忌，不只是文字。
6. 发布前用目标语言母语者抽检，尤其是标题、按钮和法务句。

- [Google Cloud Translation](https://cloud.google.com/translate)
