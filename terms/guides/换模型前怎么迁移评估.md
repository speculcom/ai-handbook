# 换模型前怎么迁移评估（How to Assess a Model Migration）

**这份指南解决什么**：换模型不是改个名字：同一套提示词在新模型上可能失效。这篇讲换之前要过的四道检查。

**怎么做**：
1. 先跑自建评测对比新旧：公共榜单只说明普遍水平，你的真实输入才说明能不能换。
2. 逐项核接口差异：参数名、流式行为、结构化输出支持、上下文长度——兼容接口不等于行为一致。
3. 重测依赖提示词的功能：同一提示词在不同模型上表现可以差很多，边界条款尤其容易漂。
4. 核许可与数据条款：新模型的许可证、数据保留政策、区域可用性可能和旧模型不同。
5. 留回滚路径：旧模型配置保留到确认期结束，出问题能一键切回。
6. 确认期用线上指标收尾：任务完成率、拒答率、成本三项对比基线，达标才下线旧模型。
