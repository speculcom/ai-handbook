# 课堂教案：模型原理与论文证据边界（Lesson - Model Mechanics and Paper Evidence Limits）

**这份教案解决什么**：学员用两篇论文摘要练「主张—证据—条件」三栏读法，再把观察连回自回归与注意力，去掉无条件的能力断言。

**课时目标**：
- 能从摘要分出研究问题、证据位置、实验条件三栏。
- 能写出至少一条作者没有主张的内容，并说明依据来自原文哪一句。
- 能用自回归生成与注意力解释输出为什么逐词产生，不说成查表或理解。
- 能区分「窗口装得下」与「窗口里的信息被用上」，并引用位置效应的结论。

**材料**：
- arXiv 1706.03762《Attention Is All You Need》摘要页：翻译任务、BLEU 与训练设置。
- arXiv 2307.03172《Lost in the Middle》摘要页：多文档问答与键值检索中的位置效应。
- 本站《论文卡-Attention Is All You Need》作为读法示例。
- 三栏工作表：主张、证据位置、条件与未主张。

**步骤**（12 分钟微课）：
1. 3 分钟读第一篇：圈出任务名与指标，写出它主张的范围。
2. 3 分钟读第二篇：把结论写成条件句，说明信息位置变化时表现怎么变。
3. 3 分钟互查：小组交换工作表，把无条件断言改写成带条件的转述。
4. 3 分钟连回机制：用自回归与注意力解释这两篇的观察，指出哪些说法证据不足。

**常见误解**：
- 把标题或摘要里的强措辞当结论；结论受任务与设置限制。
- 把长窗口当成「长文档都能答对」；信息在中间时表现可能下降。
- 把注意力当成人类式「注意到重点」；它是权重计算。
- 把某个指标提升当成能力全面升级；BLEU 对应特定翻译任务。

**评分核对**：
- 三栏工作表填完，「未主张」一栏至少一条能回连原文。
- 转述句含任务、设置与观察结果，不含「理解」「总是」这类无条件词。
- 能说明本课没有复跑实验，也不给出自测分数。

**出处**：两篇都只读摘要页即可上课。第一篇的主张限于架构与两个机器翻译任务，指标是 BLEU，摘要同时给出训练时长与 GPU 数。

第二篇在多文档问答与键值检索两个任务上观察位置效应。摘要写明相关信息在输入开头或结尾时表现往往较高，在长上下文中间时明显下降。课堂转述要带上任务与条件，不写成「模型读不懂长文档」。

- [Liu 等《Lost in the Middle》（arXiv 2307.03172）](https://arxiv.org/abs/2307.03172)
