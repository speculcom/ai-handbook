# 怎么读模型卡（How to Read a Model Card）

**这份指南解决什么**：模型卡是厂商给模型的说明书。这份指南讲读它时该看哪几栏、哪些话要打折。

**怎么做**：
1. 先看用途与限制栏：官方写明「适合什么、不适合什么」，比宣传语可靠。
2. 看评测栏时先问「在哪些基准上测的」，没有基准的分数等于没有分数。
3. 看训练数据栏：数据构成决定它可能带哪些偏见。
4. 看许可栏：能不能商用、要不要署名、衍生模型要不要同许可。
5. 看已知局限栏：厂商主动写的失败场景，比「效果拔群」更值得信。
6. 对比多家时只比同口径：同一基准、同一设置，否则数字没有可比性。

**出处**：模型卡的结构与字段参考原始论文与厂商透明度页（见下）。

- [Mitchell 等《Model Cards for Model Reporting》（FAT* 2019）](https://arxiv.org/abs/1810.03993)
- [Anthropic 透明度中心（官方）](https://www.anthropic.com/transparency)
