# 加了护栏就安全了（Guardrails Make It Safe）

**这份指南解决什么**：护栏改变的是默认路径，不是所有路径。

**大家以为**：接上厂商的护栏，系统就安全了。

**其实**：护栏拦的主要是训练与部署阶段预期内的常见路径。绕开它的内容（改写措辞的诱导、藏在工具返回或网页正文里的指令），以及护栏自己的边界，仍要靠你的权限设计、出口校验和事件流程。判断护栏有没有生效，要做一次能复现的检查（虚构示例）：输入一段带指令的不可信文本 → 处理是按真实链路走一遍 → 结果判断看它是否执行了那条指令或读出了环境变量 → 若执行了，下一步是收紧工具权限并在出口加过滤，而不是把「护栏已开启」当成结论。
