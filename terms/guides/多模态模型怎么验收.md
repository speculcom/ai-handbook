# 多模态模型怎么验收（How to Acceptance-Test a Multimodal Model）

**这份指南解决什么**：看图答得漂亮不等于能用；验收要把「看见」「看懂」「据此做事」分开测。

**怎么做**：
1. 建三组题：纯识别（OCR、物体、图表读数）、关系推理（比较、因果、空间）、任务执行（按图改代码、填表、导航）。
2. 每题保留原图与标准答案，要求模型引用图上坐标或区域；不能引用就判「蒙对」。
3. 加入对抗样本：模糊、旋转、遮挡、错别字、图表误导；看它是否承认看不见。
4. 分开测「描述」与「决策」：描述对但行动错，说明视觉到动作的链路没打通。
5. 记录 token 成本：图像 token 化很贵，长图与多图会显著推高单价。
6. 用同一组题对比至少一个基线模型；没有基线就没有「好」。
