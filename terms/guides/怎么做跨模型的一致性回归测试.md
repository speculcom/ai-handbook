# 怎么做跨模型的一致性回归测试（How to Run Cross-Model Regression Tests）

**这份指南解决什么**：模型升级不是「换个更强的就行」；同一套回归集必须前后跑，才能知道哪些能力变了、哪些只是风格变了。

**怎么做**：
1. 先固定 50–100 条回归集，覆盖常见任务、边界输入和必须拒答的场景。
2. 每条写期望要点而不是唯一答案，用要点覆盖率打分。
3. 升级前后跑同一套集，记录通过率、引用正确率、拒答率和平均长度。
4. 分开统计能力变化与风格变化：变长、变客气不等于变好。
5. 模型评审只做初筛，抽 20% 人工复核，防止位置与冗长偏差。
6. 设回滚阈值：低于阈值就回滚，不要用「整体感觉更好」上线。
7. 保留每次原始输出；系统提示、工具描述、检索库更新也各算一次变更。

**出处**：Liang 等 · HELM（arXiv 2211.09110）；Zheng 等 · LLM-as-a-Judge（arXiv 2306.05685）。
