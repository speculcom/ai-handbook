# 怎么选视觉语言模型（How to Choose a Vision-Language Model）

**这份指南解决什么**：VLM 不是「什么图都能读」；先分清描述、抽取、计数、定位、读字五类任务，再按任务选。

**怎么做**：
1. 把任务分成五类：描述、信息抽取、计数、定位坐标、读小字；VLM 强在前两类，弱在后三类。
2. 票据、截图、表单读字，优先 OCR 加文本模型，不要只靠 VLM 看图。
3. 需要框选或坐标时，确认模型支持 grounding；普通 VLM 只给文字描述。
4. 验证输入分辨率：小字、表格线在缩图后是否还能读；这常是硬上限。
5. 测幻觉：给它一张没有某物体的图，看它是否承认「看不到」。
6. 用 30–50 张真实业务图盲测，分「答对 / 部分对 / 编造」三档，不只看 demo。
7. 先估单张成本：图像 token 远多于文本 token，批量任务容易被低估。
