# 上下文窗口越大越好（Bigger Context Is Always Better）

**这份指南解决什么**：窗口大小有代价，够用比拉满更划算。

**大家以为**：上下文窗口越大，长文档就处理得越好。

**其实**：窗口变大会推高显存与延迟。长输入里，中段内容的利用也不均匀。按需要选比选最大更划算。

**出处**：
- [Lost in the Middle（arXiv 2307.03172）](https://arxiv.org/abs/2307.03172)：长上下文里中段信息的利用率低于开头与结尾。
- [Hugging Face · KV cache 文档](https://huggingface.co/docs/transformers/en/kv_cache)：KV cache 随上下文长度线性增长，直接占用显存。
