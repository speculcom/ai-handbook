# 接口兼容就等于行为一致（A Compatible API Means Identical Behaviour）

**这份指南解决什么**：兼容保证的是请求与响应的形状。

**大家以为**：只要接口兼容 OpenAI，换过去效果就一样。

**其实**：兼容保证的是请求与响应的形状；参数默认值、报错行为和输出质量各家不同。

- [vLLM OpenAI 兼容服务文档](https://docs.vllm.ai/en/latest/serving/openai_compatible_server.html)
