# 怎么判断一张图是不是 AI 生成的（How to Tell Whether an Image Is AI-Generated）

**这份指南解决什么**：单看画面已经不可靠；能站住脚的判断来自「来源、原件、凭证、时间线」四条证据链。

**怎么做**：
1. 先看来源与凭证：C2PA / Content Credentials 能记录拍摄与编辑；没有凭证不等于假，有凭证也要验签。
2. 查反向图搜与发布时间：AI 图常常找不到更早的出处。
3. 看画面线索：文字、手指、重复纹理、镜面反射、阴影方向；但模型进步会不断让这些线索失效。
4. 看噪声与压缩一致性：拼接图常有不同噪声、重复块或边缘不一致。
5. 检测模型只作辅助：它们对压缩、二次编辑和分布外图片很脆弱，概率不是判决。
6. 最可靠的是原件、拍摄链路与证人；平台应保留上传原件和处理日志。
7. 结论分三档：已证实伪造 / 高度可疑 / 无法判断；不要被迫二选一。

**出处**：C2PA · 2.1 规范；Content Authenticity Initiative。
