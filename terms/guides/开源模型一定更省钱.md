# 开源模型一定更省钱（Open Models Are Always Cheaper）

**这份指南解决什么**：开源保证的是使用权与可改性，不是免费。

**大家以为**：模型开源了，成本就一定比调用 API 低。

**其实**：自建要算硬件、运维和人力；开源保证的是使用权与可改性，不是「免费」。
