# 多卡互联值不值（Is Multi-GPU Interconnect Worth It?）

**这份指南解决什么**：多卡不是「显存加法」；先算通信、并行方式与真实吞吐，再决定掏不掏钱。

**怎么做**：
1. 先判断瓶颈：单卡显存不够、单卡算力不够、还是要更大并发；三种问题解法不同。
2. 张量并行吃互联带宽，流水并行吃显存与气泡；NVLink、PCIe、雷电的差距先查清。
3. 算有效吞吐：不是峰值 FLOPS 相加，而是端到端 tokens/s 与首字延迟。
4. 算总拥有成本：卡、主板、电源、散热、机房、电费、运维；别只算卡价。
5. 小模型与低并发通常单卡更划算；多卡适合大模型、长上下文、高并发。
6. 先租后买：用云上同规格多卡跑一周真实负载，再决定。
