# 数据标注与质检怎么看（How to Read Data Annotation and QA）

**这份指南解决什么**：「我们用了百万条标注数据」不说明质量。这篇讲怎么从标注者、一致性、质检流程三处看穿一份训练或评测数据的成色。

**怎么做**：
1. 先看标注者是谁：众包、内部员工还是领域专家，单价差在哪，数据质量大概率就在哪。
2. 看一致性指标：同一批数据多人标注的吻合度低，说明规则本身有歧义，数据噪声不会小。
3. 质检流程比标注量重要：抽查比例、返工机制、分歧仲裁，三样缺一样，规模都是虚的。
4. 「什么算对」必须写进标注规则：规则含糊，标注员只能猜，猜出来的数据会教出摇摆的模型。
5. 模型标的数据（合成数据、AI 反馈）不免检：它自带模型偏见，至少要人工抽检加评测回归兜底。
6. 数据问题最后都在评测里显形：模型行为怪异时，先查最近一批数据的规则变更，别急着调参数。

**出处**：人工标注与偏好数据流程参考 InstructGPT（RLHF）论文；「少而精数据」的证据参考 LIMA；模型自标数据与过滤机制参考 Self-Instruct（见下）。
