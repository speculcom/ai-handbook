# 榜单怎么读（How to Read a Leaderboard）

**这份指南解决什么**：误区篇说「榜单分数高不等于好用」；这篇讲怎么把榜单读出信息：谁做的、怎么测、哪里失真。

**怎么做**：
1. 先查三件事：谁维护、题目从哪来、分数怎么算——三者不明的榜单只当广告看。
2. 看题目发布时间：榜单晚于模型训练截止才有区分度；疑似泄漏的公开题集分数普遍虚高。
3. 总分拆开看：同一模型在不同任务子集上排名可以完全颠倒，按你要的任务子集比。
4. 对比要同口径：不同榜单的分数不能互比，同一榜单里不同评测条件（上下文长度、工具开关）也不能混比。
5. 看分数差有没有意义：1-2 分常在评测噪声范围内，排名相邻基本等于打平。
6. 自建口径补位：公共榜单回答「普遍水平」，你自己的 20-50 道题回答「在我这活儿上行不行」。

**出处**：口径设计参考 HELM 论文、Chatbot Arena 与 Open LLM Leaderboard 实践（见下）。
