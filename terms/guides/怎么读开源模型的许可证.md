# 怎么读开源模型的许可证（How to Read an Open-Model License）

**这份指南解决什么**：「开源」不等于随便用。模型许可证里的条件，决定你能不能商用、要不要署名、衍生模型跟不跟同许可。

**怎么做**：
1. 先分清开源软件许可和模型许可：后者常带额外条件，不能凭「开源」两个字推断。
2. 查商用条款：有的许可禁止商用，有的设规模门槛。
3. 查署名与声明：Apache 2.0 要求保留声明和 NOTICE。
4. 查衍生模型义务：同许可（copyleft）要求改出来的模型沿用同一份许可。
5. 查使用限制：不少模型许可禁止用于某些场景，违反即失效。
6. 查许可继承：微调、量化、合并后的模型带哪份许可，本站模型档案逐仓记录。

**出处**：条款原文以 Apache 官方为准，横向对照可用 Choose a License；本站模型站逐仓记录许可继承（见下）。
