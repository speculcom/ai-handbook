# 维度 3 · 本地文件

> 核心问题：**能不能读写你硬盘上的文件？读的方式是什么？**

---

## 为什么这个维度对 AI 编程工具特别重要

其他行业的 AI 工具主要处理对话和上传的文件。**编程工具的第一件事是接触代码库**，所以这一维度直接决定它能不能用。

---

## 要回答的四个子问题

### 3.1 能访问的范围

| 范围 | 判定 |
|---|---|
| 只能访问打开的文件 | 受限 |
| 工作区目录 | 标准 |
| 任意授权目录 | 宽 |
| 整个文件系统 | 极宽（需要警惕） |

**必须区分"能访问"和"默认能访问"。** 有些工具需要手动授权目录，不授权就只能看到工作区。

### 3.2 索引方式

这是 AI 编程工具的核心差异点。

| 方式 | 说明 |
|---|---|
| 全量索引 | 首次打开需等待，大仓库慢 |
| 增量索引 | 按需建立，速度快但语义检索弱 |
| 无索引 | 靠 grep / LSP，精确但不理解语义 |
| 混合 | 符号索引 + 按需语义检索 |

**判定**：写清是否有首次索引等待、大仓库表现如何。

### 3.3 大仓库表现

大型仓库（10 万行以上）的表现，是区分工具的分水岭。

```
未打开的大文件依赖索引策略，首次索引大仓库需等待。
```

**未知时**：
```
大仓库首次索引耗时本次未实测，记为未知。
```

### 3.4 符号级访问

能不能直接跳到定义、查引用、改签名？这决定了大重构的可行性。

| 能力 | 依赖 |
|---|---|
| 跳转定义 | LSP |
| 查引用 | LSP 或自有索引 |
| 跨文件重命名 | LSP |

---

## 常见错误

| 错误写法 | 问题 |
|---|---|
| `支持读写本地文件` | 没说范围，也没说索引方式 |
| `完全本地` | 混同了"能访问"和"索引在哪" |
| `支持大仓库` | 什么算大？1000 行还是 100 万行？ |
| 省略 | 无法判断 |

---

## 合格的写法

```markdown
local_files: >-
  可读写工作区文件；未打开的大文件依赖索引策略，
  首次索引大仓库需等待。
  符号级跳转依赖 LSP，重命名可用。
  **10 万行级仓库的索引耗时本次未实测，记为未知。**
```

拆解：
- 范围说清了（工作区）
- 索引方式说清了（依赖策略 + 需等待）
- 符号能力说清了（LSP）
- 不知道的老实说了

| 分区 | 关注重点 |
|---|---|

## 安全提示

本维度的记录**不构成安全建议**。

一个工具能访问你的 `.env`、SSH 私钥、数据库配置——这取决于你怎么配置它，不只是工具能力。

**如果某工具默认要求全盘访问，要在这里点出来**：

```
默认请求全文件系统访问权限；如需收紧可配置目录白名单。
```
