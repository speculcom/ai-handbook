# 推理成本（Inference Cost）

**解决什么问题**：模型每回答一次要花的钱，由输入和输出的 token 量决定。

通常按输入 token 和输出 token 分别计价，输出更贵。

同一个模型，问法不同，账单可以差一个量级。

**为什么需要知道**：这是把 AI 用在日常场景时最容易踩的坑。它也是「选模型」必须考虑的成本项。
