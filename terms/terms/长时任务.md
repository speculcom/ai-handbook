# 长时任务（Long-running Task）

**解决什么问题**：跑几小时甚至几天、跨多个上下文的复杂工作。

超出单次上下文或单次会话时长的任务，需要外部存储进度、阶段性恢复。

**为什么需要知道**：这是 Agent 能力的天花板所在。宣称能跑长任务的框架，值得重点核实它怎么存进度。
