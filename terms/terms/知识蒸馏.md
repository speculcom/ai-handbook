# 知识蒸馏（Knowledge Distillation）

**解决什么问题**：用大模型的软输出训练小模型：能力保留大半，部署容易得多。

大模型带高温 softmax 输出「软目标」，小模型学这些概率分布。

通行的「教师 / 学生」叫法是后来的通俗命名。原论文的用词是 cumbersome model 与 distilled model。

**为什么需要知道**：你能在本地跑的小模型，不少是蒸馏产物。模型名里带 -distill 或 - distilled，多半和它有关。
