# AI Agent 与聊天机器人的区别（Agent vs Chatbot）

**解决什么问题**：聊天的终点是回答，Agent 的终点是做完。

聊天机器人是「一问一答」。Agent 会自己规划步骤、调工具、检查结果，循环直到完成。

**为什么需要知道**：判断一个工具是哪种，决定了它值不值得你花时间配置。
