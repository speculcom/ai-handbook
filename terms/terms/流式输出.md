# 流式输出（Streaming Output）

**解决什么问题**：回答边生成边推送：你看到逐字出现，而不是等全文算完。

自回归模型逐 token 生成，流式模式把每个 token 即时推送给客户端。

常见实现是 SSE（服务器推送事件流）：服务器以事件流持续下发。

价值在首字延迟：长回答不必等全部算完才开始读。

中途可停：取消请求即停止生成与计费。

**为什么需要知道**：聊天界面的逐字效果、为什么能中途打断、为什么按输出 token 计费——都来自这个机制。
