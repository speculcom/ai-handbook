# llama.cpp（llama.cpp）

**解决什么问题**：在普通电脑上跑大模型的主流开源引擎，CPU 也能跑。

用 C/C++ 写的推理引擎，强调轻量与跨平台。支持 CPU + GPU 混合推理。

它是本地部署生态的底座——大量量化版本是为它准备的。

**为什么需要知道**：本地部署的默认选项。选它意味着你能用上最多的量化版本和社区支持。
