# Workflow 还是 Agent（Workflow vs Agent）

**解决什么问题**：先判断这件事该不该做成自主体。

Anthropic 的区分：workflow 用预定义代码路径编排模型与工具。

agent 则由模型动态决定自己的流程和工具使用。

官方建议从最简方案开始，够用就不必构建自主体系统。

**为什么需要知道**：选型的第一问。把 workflow 硬做成 Agent，只会更贵更不可靠。
