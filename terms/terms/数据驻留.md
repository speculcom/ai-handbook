# 数据驻留（Data Residency）

**解决什么问题**：你的数据存在哪个区域，由谁决定。

AWS 官方：客户选择在哪个 AWS 区域存储客户内容。

官方称除提供服务所必需或依法要求外，不会把内容移出所选区域。

**为什么需要知道**：「数据不出网」在云端的具体形态。合规审查时这是要拿书面承诺的一项。
