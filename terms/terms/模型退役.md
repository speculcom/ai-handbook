# 模型退役（Model Retirement）

**解决什么问题**：云端模型会被下线，这是选型时要算的风险。

微软官方区分两阶段：弃用后新客户不能再部署，已有部署仍可用。

退役后所有推理请求返回 410 Gone。

官方称标准生命周期约 18 个月，并在退役前至少提前 60 天通知。

**为什么需要知道**：「这家 API 会不会哪天关掉」有具体答案：会，而且有时间表。
