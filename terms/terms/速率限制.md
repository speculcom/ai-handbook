# 速率限制（Rate Limiting）

**解决什么问题**：API 对你单位时间能发多少请求的配额。

HTTP 429 表示「请求过多」，MDN 说明它通常由速率限制触发。

配额用尽时服务端拒绝请求，客户端需等待后重试。

**为什么需要知道**：跑批量任务时最先撞的是它，不是模型能力。
