# 智能体 / Agent（Agent）

**解决什么问题**：让模型不止回答，还能自己动手。调工具、查资料、写文件，循环执行直到完成。

给模型配上目标、工具和循环，让它自主执行多步骤任务的一套做法。

关键区别：普通问答是「你问一句它答一句」。Agent 是「给它一件事，它自己走到完成」。

**别名**：智能体、代理

**为什么需要知道**：这是本站 harness 分区存在的全部理由。如果你只需要问答，不需要 Agent。
