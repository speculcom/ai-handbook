# 自托管成本（Self-hosting Cost）

**解决什么问题**：本地跑不花钱，但硬件、电费、运维都是真实成本。

设备购置、电力、显存扩容与维护工作构成的总成本。

**为什么需要知道**：它让「本地一定比 API 便宜」这个常见假设变得可验证。要按你的实际使用量算。
