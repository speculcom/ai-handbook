# 预览版与正式版（Preview vs GA）

**解决什么问题**：模型 API 的两种成熟度，决定能不能上生产。

微软官方对 Preview 的定义：它是实验性的。权重、运行时与 API 结构都可能变，且不保证转为正式版。

官方明确不建议把预览模型用于生产负载。

正式版（GA）的权重与 API 固定。

**为什么需要知道**：选 API 先看这个标签。预览版更新，但随时会变。
