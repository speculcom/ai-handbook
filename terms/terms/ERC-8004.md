# ERC-8004（ERC-8004）

**解决什么问题**：用三套链上注册表给 agent 一个可移植身份、可查询声誉和可验证的执行结果，让互不相识的 agent 也能判断「该不该把任务交给它」。

ERC-8004 定义 Identity / Reputation / Validation 三套注册表：身份用 ERC-721 表示并指向注册文件，声誉记录客户反馈，验证把执行结果交给质押重跑、zkML 或 TEE 等机制核验。

它只做发现与信任信号，不规定支付、通信或业务逻辑；x402、A2A 等协议可以接在它上面。

**为什么需要知道**：Agent 经济里最缺的不是能力，而是「你是谁、以前做得怎么样、这次做得对不对」。没有可移植的身份与声誉，每次跨组织协作都要从零建立信任。

**边界**：标准仍在 Draft 阶段，不同链的部署与实现可能不一致；声誉可以被刷，验证机制也有成本和信任假设。它不解决私钥管理、责任归属与法律合规，不能把「注册过」当成「可信」。

**怎么判断用不用**：需要跨组织发现 agent、携带历史声誉或做第三方验证时，ERC-8004 提供共同语言；单组织内部用现有账号体系与审计日志通常更直接。
