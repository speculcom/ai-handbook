# 首字延迟（Time To First Token, TTFT）

**解决什么问题**：从发出提问到看到第一个字要多久。这个数字决定「感觉快不快」。

生成第一个 token 所花的时间。它主要由提示词长度和是否需要预填充决定。

**为什么需要知道**：这是感知速度的关键指标。一个模型每字都很快但首字要等3 秒，用起来依然会觉得慢。
