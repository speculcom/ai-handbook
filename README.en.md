# AI Handbook (ai-handbook)

> 中文版：[README.md](./README.md)

One handbook, three parts: **learn AI · use AI tools · run AI models.** Primarily Chinese, bilingual, every judgment carrying an official source.

This is the **merged repo** (2026-10, v7 D8) of the three content columns of the specul.com site group. Previously each column had its own repo (ai-glossary / ai-agent-guide / ai-quantized-llm), with content and brand assets drifting separately — fixing one place meant fixing three. After the merge there is exactly one shared core: the three subtrees share the brand and shell under `shared/`, and the number conventions and gates are identical site-wide.

## The three subtrees

| Subtree | Question it answers | Rendered as |
|---|---|---|
| `terms/` | What are these terms, and why should you know them? | [learn.specul.com](https://learn.specul.com/) |
| `tools/` | Which agent / runtime / tool should you use? | [tools.specul.com](https://tools.specul.com/) |
| `models/` | With dozens of quantized builds of the same model, which should I download? | [models.specul.com](https://models.specul.com/) |

Each subtree has its own `README.md` (content map, field schema, validator); this file only carries the master table of contents and the shared discipline.

## Shared core (charter: exactly one copy)

`shared/brand/` is the **single** vendored copy of the site-wide brand assets (`brand.css` / `brand.js` / `shell.mjs` / `site.css`) inside this repo; all three subtree builds take them from here. The sources of truth live in the workspace at `www.specul/` and `_sites/_template/`; copy consistency is enforced by `_audit/brand-sync.mjs` (a `brand/` directory appearing under any subtree fails the gate).

## Shared discipline

1. **Fixed-dimension comparison** — dimensions do not change per object, so cross-comparison stays possible
2. **Every judgment carries an official source** — no impressions; links point to release pages or source code
3. **Unknown is a legitimate answer** — if it cannot be found, say so; never invent
4. **No overall ranking** — a weighted total hides trade-offs, and trade-offs are the decision basis
5. **Index only, never host** — no downloading or redistributing third-party weights or binaries

## Build and validation

- Three build entry points: `terms/scripts/build.mjs` · `tools/sites/build.mjs` · `models/scripts/build.mjs` (each reads only this repo; one clone builds all three sites)
- Three validators: `scripts/validate.mjs` in each subtree; non-compliant data fails the build outright
- The stats block in this file and `llms.txt` are generated by `_audit/gen-repo-docs.mjs` from the three subtrees' data — do not edit by hand
