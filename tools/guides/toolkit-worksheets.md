## [怎么用这页|How to use]

四张表用于评审会与上线前检查；复制到你的仓库，按项目填。

### 13. 项目立项检查表

```text
- [ ] 目标一句话：要解决谁的什么问题
- [ ] 不做清单：明确不做什么
- [ ] 数据来源与许可：能否使用、能否留存
- [ ] 模型与工具：主选、备选、许可证
- [ ] 成本上限：月调用/硬件/人力
- [ ] 验收指标：三条可量化
- [ ] 失败回滚：谁负责、怎么退
- [ ] 时间盒：到哪天必须评审
```

### 14. 内容发布前检查表

```text
- [ ] 事实：每条结论有来源与日期
- [ ] 引文：单条不超过 100 字符或一句
- [ ] 权利：图片/音乐/字体/数字人许可已登记
- [ ] 隐私：无客户姓名、订单号、密钥
- [ ] 标注：需要 AI 生成标注的平台已标注
- [ ] 版本：模型版本与生成参数已存档
- [ ] 可访问性：字幕、对比度、替代文本
- [ ] 回滚：发布后 24 小时内可撤
```

## [常见误用|Common misuses]

- 立项表只写目标：不写不做清单，范围一定蔓延。
- 发布表只查事实：不查权利，最容易返工。
- 迁移表只测一条：样本太少，结论不可用。
- 泄露表只填一半：第三方子处理者最常被漏。
