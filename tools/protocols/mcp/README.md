# MCP 分区实测任务集

**任务清单尚未编写。** 协议已就绪，见 [`_protocol.md`](./_protocol.md)。

**注意**：MCP 实测与工具分区根本不同 —— 不测「能不能干活」，
测「接口是否可用、边界是否清楚」。

## 五项测试

| # | 测试项 | 核心问题 | 状态 |
|:--:|---|---|---|
| 1 | 安装与依赖 | 装得上吗，依赖缺失时报错是否可诊断 | 待设计 |
| 2 | Tool 列表一致性 | 文档说的和实际提供的一致吗 | 待设计 |
| 3 | 传输兼容性 | 在几个主流客户端验证过可用 | 待设计 |
| 4 | 输出可用性 | 能直接消费还是要二次解析 | 待设计 |
| 5 | 权限边界 | 默认范围多宽，能收紧吗，越界是否被拒 | 待设计 |

**安全提示**：权限测试可能真的读到敏感文件。
建议在专门测试目录或容器内进行，不要在真实项目里测。
