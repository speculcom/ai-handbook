# C02 · 无 TTY 环境（CLI 特有）

**形态**：CLI
**基线仓库**：`atlas-bench-fixture` @ `bench-baseline`（commit `5db3db6`）
**为什么重要**：很多 CLI 工具在无 TTY 环境下会卡在交互审批。这会让它们根本进不了 CI。

---

## 测试环境

```bash
# 无 TTY 环境模拟
env -i PATH=/usr/bin:/bin HOME=/tmp/ci <tool> --print "..."
```

（`<tool> --print` 换成该工具的单次执行等价命令，见 C01）

## 记录项

| 记录项 | 说明 |
|---|---|
| 无 TTY 是否正常 | 是 / 否 / 报错信息 |
| 是否需要配置文件 | 默认配置在无家目录时是否可行 |
| 是否需要交互确认 | 审批提示会卡住吗 |
| 能否容器化 | 是否依赖系统特有组件 |

---

## 判定

| 档位 | 标准 |
|---|---|
| **CI 友好** | 无 TTY 可运行，无需交互 |
| **需配置** | 加参数或环境变量后可跑 |
| **CI 不友好** | 必须有 TTY 或必然卡在交互 |
