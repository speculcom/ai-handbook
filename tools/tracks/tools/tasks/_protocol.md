# MCP 分区实测协议

MCP 实测和工具分区**根本不同**：

| 分区 | 测什么 |
|---|---|
| ide / cli | 能不能把活干完 |
| **mcp** | **接口是否可用、边界是否清楚** |

因为 MCP server 是被调用的接口，不是独立工作的工具。

---

## 一 · 五个测试项

### 测试 1 · 安装与依赖

**能不能装上，是第一道门槛。**

| 记录项 | 说明 |
|---|---|
| 安装方式 | npx / uvx / docker / 手动 clone |
| 依赖清单 | node / python / go 版本要求 |
| 依赖缺失时的报错 | 是否可诊断 |
| 首次启动耗时 | 含依赖下载 |

**常见失败**：文档说支持某 transport，实际客户端连不上（见测试 3）。

---

### 测试 2 · Tool 列表一致性

**文档说的和实际提供的，往往不一致。**

| 记录项 | 说明 |
|---|---|
| 文档声明的 tool 数 | |
| 实际握手返回的 tool 数 | |
| 缺失的 tool | 文档有但实际没有 |
| 多出的 tool | 实际有但文档没写 |
| tool 描述是否准确 | 参数名、必填项、语义 |

**这一项经常发现问题**，也是最有价值的实测内容之一。

---

### 测试 3 · 传输兼容性

**在哪些客户端里验证过可用？**

| 记录项 | 说明 |
|---|---|
| 声明支持的传输 | |
| 实际测试的客户端 | 具体是哪个客户端的哪个版本 |
| 连不上的情况 | 报错原文 |
| 版本敏感性 | 换客户端版本后是否失效 |

**判定**：

| 档位 | 标准 |
|---|---|
| **通用** | 在 ≥3 个主流客户端验证可用 |
| **有限** | 只在 1-2 个客户端验证过 |
| **未验证** | 无实测记录 |

---

### 测试 4 · 输出可用性

**能返回 ≠ 返回得可用。**

| 输出类型 | 可判定标志 |
|---|---|
| 结构化 JSON | 有固定 schema，可直接解析 |
| 半结构化 | Markdown 表格 / 列表 |
| 自由文本 | 需要再问一次才能用 |

**测试方法**：

对每个 tool 造一个真实输入，看输出能否直接喂给下一步处理。

```markdown
| tool | 输出类型 | 可直接消费 | 需要二次解析 |
|---|---|---|---|
| fs.read_text | 结构化 | 是 | — |
| git.log | 半结构化 | — | 是，需解析表头 |
| web.fetch | 自由文本 | — | 是，需再问 |
```

**关键指标**：有多少比例的 tool 输出需要二次解析。

---

### 测试 5 · 权限边界

**这是 MCP 分区最需要实测的部分。**

| 测试 | 方法 | 记录 |
|---|---|---|
| 默认范围 | 不加任何配置，直接调用 | 实际能访问什么 |
| 可收紧性 | 加白名单参数 | 收紧后是否生效 |
| 越界尝试 | 请求白名单外的路径 | 是否被拒绝，报错是否清晰 |
| 写操作 | 尝试写文件 / 执行命令 | 是否有确认，默认行为 |

**关键记录**：

```markdown
## 权限边界实测

默认配置下可访问：
- <实际测到的范围>

白名单收紧后：
- <配置参数> → 访问 <范围> 被拒绝
- 报错信息：<原文>

写操作：
- 默认行为：<可直接写 / 需确认 / 不支持>
```

**单个 server 安全 ≠ 叠加后安全。**

```markdown

- filesystem（可读写全盘）

- postgres（可写）

```

## 四 · 硬性要求

| # | 要求 |
|:--:|---|
| 1 | 有完整环境记录（含测试客户端与版本） |
| 2 | 每个 server 有五项测试的记录 |
| 3 | 报错信息原文引用，不概括 |
| 4 | 权限边界有实际越界尝试记录 |
| 5 | 有局限说明 |
| 6 | **记录测试者此前用过哪些 server**（避免熟悉度偏差） |

---

## 五 · 安全提示

**实测本身可能造成实际影响。**

| 测试 | 风险 |
|---|---|
| 权限边界测试 | 可能真的读到敏感文件 |
| 写操作测试 | 可能真的改文件 |
| 组合测试 | 多个高权限 server 同时运行 |

**建议**：
- 用专门的测试目录，不要在真实项目里测
- 涉及凭据的 server 用只读 token
- 可执行命令类 server 放在容器里测

**实测报告里不要粘贴真实凭据、真实敏感文件内容。**

## 六 · 与条目字段的对应

| 实测项 | 对应字段 |
|---|---|
| 安装与依赖 | 正文「上手成本」 |
| Tool 列表一致性 | `axes.tools` |
| 传输兼容性 | `mcp.transport` |
| 输出可用性 | `axes.tools`（输出质量部分） |
| 权限边界 | `mcp.scope` |
| 凭据相关 | `mcp.auth` |

**实测结果应回填到条目里**，并更新 `last_verified` 与 `confidence`。
