## 一句话定位

**v0 是 Vercel 的提示词到全栈应用平台**：聊天生成 Next.js 应用，VM 沙箱内跑真终端与预装 agent
（claude 可直接用），GitHub 同步进你的仓库，publish 走 Vercel 部署链——权限三档 Ask/Auto/Full，
自定义模型是 Enterprise 面。

## 适合与不适合

适合：Next.js/Vercel 栈团队、要沙箱终端与预装 agent、企业席位并入 Vercel 账号体系。
不适合：栈不在 Vercel 生态、非 Enterprise 要自定义模型。
