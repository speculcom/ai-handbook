# C01 · 非交互模式可用性（CLI 特有）

**形态**：CLI（决定能不能进 CI，是 CLI 形态最重要的测试）
**基线仓库**：`atlas-bench-fixture` @ `bench-baseline`（commit `5db3db6`）

---

## 测试方法

对每个工具，跑一次它的「单次执行」等价命令。如 `--print` / `-p` / `run`：

```bash
<tool> --print "把 src/recipes/ 下某个 recipe 的超时常量改成 5000"
```

> 若工具没有 `--print`，用其官方等价单次执行参数；没有单次模式则记「不支持」。

## 记录项

| 记录项 | 说明 |
|---|---|
| 是否有单次执行模式 | 没有就记「不支持」 |
| 输出是否可控 | 纯文本 / JSON / 可解析 |
| 退出码语义 | 成功 0？失败非 0？ |
| 能否管道使用 | 输出能否直接进下一个命令 |

---

## 判定

| 档位 | 标准 |
|---|---|
| **可用** | 完整任务 + 结构化输出 + 正确退出码 |
| **勉强** | 能完成但输出混杂日志，需二次解析 |
| **不可用** | 无单次模式，或退出码不可靠 |
