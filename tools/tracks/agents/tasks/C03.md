# C03 · Git 集成深度（CLI 特有）

**形态**：CLI
**基线仓库**：`atlas-bench-fixture` @ `bench-baseline`（commit `5db3db6`）

---

## 分级

| 级别 | 说明 | 测试方法 |
|---|---|---|
| **L0 无** | 纯文件操作 | 改完后看 `git status` 是否干净 |
| **L1 只读** | 能看 diff，不能提交 | 让它解释一次变更 |
| **L2 可提交** | 能 commit | 让它改完直接提交 |
| **L3 完整** | 分支 / PR / 变基 | 让它开分支改完合回 |

> **L0 不算缺陷**——有些工具刻意不做 Git 操作。要写清是「设计选择」还是「能力缺失」。

| Aider | L3 | 自动 commit，可配分支策略 |
| OpenCode | L2 | 可提交，分支需手动 |
| XXX | L0 | 只改文件，git 需手工处理 |

---

## 实测方法

在 `bench-baseline` 状态下让工具完成一个小的文件改动任务。然后观察：
1. 改完 `git status` 是否干净（L0 判定）
2. 能否让它解释这次 diff（L1）
3. 能否让它直接 `git commit`（L2）
4. 能否让它开分支并合回（L3）

逐级尝试，记到能达到的最高一级。
