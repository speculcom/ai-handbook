# AI Tools (ai-handbook / tools)

> Which agent / runtime / tool should you use?

Organizes "AI products that do work for you" along two levels: **category** (coding / chat / image / video / audio / research / automation / framework / mcp / runner — 10 in all) and **form** (IDE / CLI / vendor cloud / web / app / framework / MCP / local app — 8 values), compared across one fixed set of dimensions.

## Size (computed from data — see the build scripts under `scripts/` and `_audit/gen-repo-docs.mjs`)

173 profiles across 10 categories (coding 41, chat 14, image 13, video 12, audio 10, research 11, automation 14, framework 22, mcp 24, runner 12), compared across a fixed set of 8 dimensions.

## Content map

- `categories.md` — The 10 categories: admission criteria / boundary rulings / what we do not take
- `tracks/<category>/products/` — Eight-dimension profiles (the directory IS the category; research / automation / runner being inventoried)
- `axes/` — Comparison dimension definitions (what each dimension asks)
- `SCHEMA.md` — Field schema

## What this repo does not do

- No overall ranking — a weighted total hides trade-offs
- No hands-on testing (untested dimensions are marked "unknown", never guessed)
- No "best to use" — only "who it suits / who it does not"

## Schema and validation

- Field schema: `SCHEMA.md`
- Validator: `scripts/validate.mjs` (non-compliant entries fail the build)
- Cross-category links: every profile needs at least 1 `related` entry from **another category** (probe: `_audit/link-graph.mjs`)
