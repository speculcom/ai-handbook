指南

怎么读榜单：先看测什么，再看谁在测

榜单不是模型排行榜。先看它测什么、题集什么时候发布、评委是谁、分数怎么算，再决定这个分数对你的选型有没有意义。

读指南 →
指南

评测污染怎么查：先看题集时间，再做检索

模型分数高，不一定是能力强，可能是题目见过。污染检查不是一句“我们做了去重”，而是可复现的题集时间线 + 检索证据。

读指南 →
指南

Agent 与工具调用怎么评：环境、工具、步数、评分

Agent 分数不是“模型会不会用工具”，而是“在给定环境、工具集、步数上限和评分器下，任务能不能完成”。四件事缺一件，分数就不可比。

读指南 →
指南

多模态评测怎么读：图像、视频、文档三套口径

多模态分数受分辨率、抽帧、OCR 和答案格式影响。先确认它测的是哪一类输入，再谈分数能不能比。
