GLM-5.4：首个 Loop Transformer 旗舰GLM-5.4: the first Loop Transformer flagship

智谱把 750B 基座的 28 层循环跑两遍，用重复计算换推理深度，而不增加参数；官方称智能水平达到 2–3T 级模型。原生多模态与「泛 Coding」是主场景：编程之外还覆盖视频创作、游戏开发与 3D 建模。2026-11-23 发布，API 与开源权重尚未放出。Z.ai runs 28 layers of its 750B base through two loops, trading repeated compute for reasoning depth without adding parameters; it claims intelligence in the 2–3T class. Native multimodality and “generalised coding” are the pitch, extending beyond code to video, game development and 3D modelling. Announced 2026-11-23; the API and open weights are not out yet.

为什么值得看Why it matters

它代表 2026 年的一条新路线：不把参数继续堆到 2T，而是让同一组层循环、把计算深度变成新的 Scaling 轴。对关注推理成本、长程 Agent 与多模态 Coding 的团队，这是必须知道的一个对照点；但它目前只是发布，不是可部署权重。It represents a 2026 route: instead of pushing parameters to 2T, loop the same layers and make compute depth a new scaling axis. For teams watching inference cost, long-horizon agents and multimodal coding, it is a required comparison point — but it is an announcement, not deployable weights.

边界 / 它没主张什么Boundary / what it does not claim

「2–3T 级」是厂商自评，官方尚未公布基准分数；循环两遍意味着同参数下计算量约翻倍，不能把 750B 当成 750B 的算力成本。它不是开放权重，也不能本地部署；API 与权重都还没放，发布时间不等于可用时间。它没主张「Loop 一定优于更宽模型」或「750B 已超过 2T 级」。“2–3T class” is a vendor claim with no published benchmark scores; looping twice means roughly double the compute at the same parameter count, so 750B is not 750B of compute cost. It is not open weights and cannot be hosted locally; neither API nor weights are available, and announcement time is not availability time. It does not claim looping always beats a wider model, or that 750B already exceeds a 2T model.
