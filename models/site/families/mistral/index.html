Mistral AI（法国）Mistral AI (France)　·　当前代current generation Mistral Large 4Mistral Large 4（2026-10）

MistralMistral模型家族谱系卡model family lineage card

欧洲开放权重旗舰：1T 级 MoE + 1M 上下文 + 视觉输入，许可为修改版 MIT（MaaS 需单独授权）。适合需要「开放权重 + 欧洲合规叙事 + 多语言」的部署者；本地运行门槛极高，官方提供 NVFP4 量化档与 DSpark 投机解码草稿头。A European open-weight flagship: 1T-class MoE, 1M context and vision input, under a modified MIT licence (separate MaaS grant needed). For deployers who need open weights, a European compliance story and multilingual coverage; local hosting is extremely demanding, and the official release includes an NVFP4 checkpoint and a DSpark speculative-decoding draft head.

这里没有录 Mistral 系列的量化对比：Mistral-Small-4-119B 的第三方 GGUF 下载量约 8.4 万（2026-10-30 复测），未过 METHODOLOGY 的量化生态门槛（约 30 万）。This site does not cover Mistral quantisations: Mistral-Small-4-119B's third-party GGUF downloads (~84k, re-measured 2026-10-30) fall below the METHODOLOGY ecosystem threshold (~300k).

官方能力声明（带出处）Official capability claims (with sources)

  • 官方模型卡：「a 1 trillion-parameter natively multimodal Mixture-of-Experts model with 49 billion active parameters per token (52 billion including embeddings and output layers)」——1T 总参、49B 激活、原生多模态 MoE；3,800 张 Grace Blackwell 训练。Official model card: "a 1 trillion-parameter natively multimodal Mixture-of-Experts model with 49 billion active parameters per token (52 billion including embeddings and output layers)" — 1T total, 49B active, natively multimodal MoE; trained on 3,800 Grace Blackwell GPUs.出处 ↗source ↗
  • 官方模型卡：128 路由专家、每 token 激活 4 个 + 1 共享专家；1M 上下文；160+ 语言；文本 + 图像输入。Official model card: 128 routed experts, 4 active per token plus 1 shared; 1M context; 160+ languages; text + image input.出处 ↗source ↗
  • 官方模型卡：Artificial Analysis Coding Agent Index 48%，与 GLM-5.3 基本持平，每任务少 47% token；AA Intelligence Index v5 得分 26。第三方指数，不是这里实测。Official model card: 48% on the Artificial Analysis Coding Agent Index, effectively tied with GLM-5.3 while using 47% fewer tokens per task; AA Intelligence Index v5 score 26. Third-party indices, not measured here.出处 ↗source ↗
  • 官方 README（Small 4）：「119B parameters, with 6.5B activated per token」+「256k context length」+ 128 experts / 4 active 的 MoE 结构。Official README (Small 4): "119B parameters, with 6.5B activated per token", "256k context length", MoE with 128 experts and 4 active.出处 ↗source ↗
  • 官方 README（Medium 3.5）：「a dense 128B model with a 256k context window」，指令遵循、推理、编码合一；取代 Medium 3.1 与 Magistral。Official README (Medium 3.5): "a dense 128B model with a 256k context window", unifying instruction-following, reasoning and coding; supersedes Medium 3.1 and Magistral.出处 ↗source ↗
