Open WebUI

open-webui / open-webui

自托管 AI 聊天/工作台：接 Ollama 与 OpenAI 兼容 API，带 RAG、联网搜索、多用户权限与工具扩展。A self-hosted AI chat and workbench for Ollama and OpenAI-compatible APIs, with RAG, web search, multi-user permissions and tool extensions.

159.1k stars 23119 forks Svelte 语言Language NOASSERTION 许可License 最近推送Last push 2026-11-19

为什么选Why choose it

  • 一个界面接 Ollama、OpenAI 兼容 API 和多种模型后端；本地/内网部署，数据不离开自己的机器。A full chat UI rather than a raw API.
  • 内置 RAG、网页搜索、文档上传、多用户与 RBAC、工具/函数调用，适合团队内部知识库与模型网关。RAG, search and multi-user controls are built in.
  • 159k star、迭代快，Docker 一条命令起；比自己写聊天前端 + 权限 + RAG 省很多。Works with local and hosted model endpoints.

不适合Not for

自定义许可：BSD-3 基础 + Open WebUI 品牌条款；去掉品牌有用户数/商业授权条件，商用前读 LICENSE。You need a single-user desktop app with no server.
它不是推理引擎；吞吐、量化、GPU 调度还是交给 Ollama / vLLM / SGLang。You cannot manage accounts and data retention.

最小上手Minimum setup

  1. 用 Docker 起服务，先接一个 Ollama 或 OpenAI 兼容 endpoint，确认流式输出与模型列表。Run it with one local model and create two users.
  2. 开一个普通用户账号，上传一份 PDF 试 RAG，检查引用、权限与数据落盘位置。Upload a small document and test RAG citations.
  3. 再配联网搜索/工具与 RBAC，观察并发、日志、反向代理与备份。Check what traces and documents are stored before inviting others.

依赖与成本Dependencies and cost

Docker / Python；Ollama 或 OpenAI 兼容 API；向量库/嵌入模型；生产要反向代理、持久卷与备份。Check runtime, model weights and external service dependencies in the README.
