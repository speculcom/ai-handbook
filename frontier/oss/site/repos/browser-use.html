Browser Use

browser-use / browser-use

让 LLM 通过浏览器操作网页：元素定位、点击、输入、截图与多步任务。Let an LLM operate a web browser: locate elements, click, type, take screenshots and complete multi-step tasks.

121.5k stars 13575 forks Python 语言Language MIT 许可License 最近推送Last push 2026-11-18

为什么选Why choose it

  • 把浏览器操作封装成 agent 工具，适合网页型任务。Turns browser actions into a model-readable loop instead of brittle selectors alone.
  • 对页面元素与视觉结合，比纯坐标点击更稳。Screenshots and DOM signals can be combined for recovery.
  • 生态活跃，示例与集成多。Useful for tasks that have a web UI but no API.

不适合Not for

不需要登录、只读 API 就能完成的任务，优先用 API。The target site offers a stable API; browser automation is slower and more fragile.
高对抗或强风控网站；自动化可能触发封禁。You cannot isolate credentials or tolerate UI changes.

最小上手Minimum setup

  1. 装 Playwright 浏览器依赖，跑一个“搜索并打开第一页”的最小示例。Run against a staging account and a simple two-step task.
  2. 换成自己的目标站点，先只读不写。Log every click, input and screenshot; check where it loses the page state.
  3. 记录失败步骤与页面版本，再加重试/人工确认。Add domain allowlists and a hard stop before using real credentials.

依赖与成本Dependencies and cost

Python + Playwright/Chromium；需要 LLM API；生产要浏览器隔离与代理。Check runtime, model weights and external service dependencies in the README.

许可与使用边界License and usage boundaries

代码 MIT；浏览器里的内容、账号与站点条款仍归原站，自动化前读 robots/ToS。Code is MIT; model weights, training data and generated content may have separate terms — check each before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.

替代与相邻Alternatives and neighbors

  • Stagehand — 特定场景Niche，TypeScript 浏览器自动化框架：自然语言动作与代码动作混用，面向可控的网页 agent。A TypeScript browser-automation framework that mixes natural-language actions with deterministic code actions.
  • LangGraph — 生产可用Production，把 agent 写成有状态图：节点、边、检查点、人工确认与回滚都能显式表达。Write an agent as a stateful graph: nodes, edges, checkpoints, human approval and rollback are explicit.
  • OpenHands — 生产可用Production，能读代码、改代码、跑命令的软件工程 agent，提供 CLI、Web 界面与沙箱运行时，可接本地或云端模型。A software-engineering agent that can read code, edit it and run commands, with CLI, web UI and a sandboxed runtime.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。Run a small sample first, then decide on production; never start with production data.
