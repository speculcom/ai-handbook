TruLens

truera / trulens

LLM 应用与 agent 的评测、追踪工具，基于 OpenTelemetry，把检索、生成与评分串成可解释的 trace。Evaluation and tracing for LLM apps and agents on OpenTelemetry, connecting retrieval, generation and feedback into an explainable trace.

3.7k stars 403 forks Python 语言Language MIT 许可License 最近推送Last push 2026-11-20

为什么选Why choose it

  • 反馈函数会给出评分理由，定位是检索错还是生成错。Feedback functions attach scores to individual trace spans.
  • OTel 原生，trace 能进现有观测后端，不被单一平台锁死。The trace shows why an answer was produced, not only the final score.
  • RAG triad 等模板直接可用，适合版本对比与回归。Works with several orchestration frameworks.

不适合Not for

偏评测与追踪，不是完整日志/告警/成本平台。You only need aggregate metrics with no span-level diagnosis.
评分器得自己校准，不能拿默认分数当真理。You cannot run an instrumented service.

最小上手Minimum setup

  1. pip 装 trulens，包一层现有 RAG/agent 调用，先接一个反馈函数。Instrument one RAG chain and record a trace.
  2. 跑 10–20 条代表性样本，看 trace 里检索与生成分别哪里掉分。Attach a faithfulness feedback function.
  3. 把评分接进 CI 或发布前对比，不要只看单次总分。Find the lowest-scoring span and inspect its retrieved context.

依赖与成本Dependencies and cost

Python + 模型 API 或本地推理；可接 OTel 兼容后端。评测集与评分器要自己准备。Check runtime, model weights and external service dependencies in the README.

许可与使用边界License and usage boundaries

代码 MIT；模型与评测数据另有条款。Code is MIT; model weights, training data and generated content may have separate terms — check each before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。Run a small sample first, then decide on production; never start with production data.
