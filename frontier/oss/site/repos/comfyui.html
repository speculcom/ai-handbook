ComfyUI

comfyanonymous / ComfyUI

节点式图像/视频生成工作流，把模型、采样、控制网、后处理拼成图。A node-based image and video generation workflow that wires models, samplers, ControlNet and post-processing into a graph.

147.5k stars 17637 forks Python 语言Language GPL-3.0 许可License 最近推送Last push 2026-11-18

为什么选Why choose it

  • 节点图可复用、可分享，复杂工作流表达力强。Graph workflows are reproducible and inspectable.
  • 社区节点与模型生态庞大。Supports many models and control adapters.
  • 本地跑，显存与模型可控。The node ecosystem extends without forking the core.

不适合Not for

只想输入一句话出图，Fooocus 更简单。You want a one-click app with no graph editing.
节点依赖多，版本冲突要会排。You need a production API without managing custom nodes.

最小上手Minimum setup

  1. 读 README / quickstart，确认 运行时 版本与系统依赖。Load the default text-to-image workflow and render one image.
  2. 按官方示例跑最小用例，记录模型/权重、密钥与数据路径。Save the workflow JSON with the model, seed and sampler.
  3. 换成自己的 1–2 个样本，观察日志、显存/内存与失败模式。Pin custom-node versions before sharing the workflow.

依赖与成本Dependencies and cost

通常需要 GPU（10–24GB+ 视模型而定）与模型权重；视频任务还要解码、存储与更长生成时间。Check runtime, model weights and external service dependencies in the README.

代码许可为 仓库 LICENSE；模型权重、训练数据与生成内容可能另有条款，商用前逐项核对。Code is GPL-3.0; model weights, training data and generated content may have separate terms — check each before commercial use.

替代与相邻Alternatives and neighbors

  • Stable Diffusion WebUI — 先试这个Start here，最经典的 SD 图形界面，文生图、图生图、LoRA、ControlNet 都在一个页面。The classic Stable Diffusion web UI: text-to-image, image-to-image, LoRA and ControlNet on one page.
  • Fooocus — 轻量Lightweight，把 SDXL 的常用参数收起来，主打“少调参也能出好图”。A simplified SDXL interface that hides most parameters and aims at good images with little tuning.
  • InvokeAI — 生产可用Production，面向创作者的图像生成工作台，统一画布、图层、模型管理与批量生成。A creator-oriented image generation workbench with a unified canvas, layers, model management and batch generation.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。Run a small sample first, then decide on production; never start with production data.
