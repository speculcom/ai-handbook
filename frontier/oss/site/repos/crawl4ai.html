Crawl4AI

unclecode / crawl4ai

面向 LLM 的网页抓取与清洗：异步爬取、浏览器渲染、去噪、Markdown/JSON 输出、分块与缓存，适合把网页变成 RAG 可用的语料。LLM-oriented web crawling and cleaning: async crawling, browser rendering, boilerplate removal, Markdown/JSON output, chunking and caching — turning pages into RAG-ready corpus.

87.6k stars 9143 forks Python 语言Language Apache-2.0 许可License 最近推送Last push 2026-11-20

为什么选Why choose it

  • 输出直接是 Markdown/JSON，少写一套清洗管线。Outputs Markdown/JSON directly, removing a separate cleaning pipeline.
  • 异步与浏览器渲染能处理大量动态页面。Async crawling and browser rendering handle many dynamic pages.
  • 缓存、分块和结构化字段适合接向量库。Caching, chunking and structured fields plug into vector stores.

不适合Not for

不绕过付费墙、登录或 robots 限制；合规责任在使用者。Does not bypass paywalls, logins or robots restrictions; compliance is the operator’s job.
大规模抓取要代理、限速与反封策略，成本不低。Large crawls need proxies, rate limits and blocking strategy — not free.
不是搜索引擎，也不做网页排名。Not a search engine and does not rank pages.

最小上手Minimum setup

  1. pip install crawl4ai，跑一次单页抓取，确认浏览器依赖已装。pip install crawl4ai, crawl one page and confirm browser dependencies are installed.
  2. 开 Markdown 与去噪，检查表格/代码块是否保留。Enable Markdown and boilerplate removal; check tables and code blocks survive.
  3. 再接分块与向量库，先小批量测重复率与失败率。Then add chunking and a vector store; measure duplication and failure rate on a small batch.

依赖与成本Dependencies and cost

Python + Playwright/Chromium；网络出口与代理；大规模要队列、缓存与对象存储。Python + Playwright/Chromium; outbound network and proxies; large jobs need queues, cache and object storage.
