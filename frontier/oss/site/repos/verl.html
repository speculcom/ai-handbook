训练与微调Training & Fine-tuning规模 / 性能Scale / performance

verl

volcengine / verl

字节跳动的 RL 训练框架：面向 LLM Agent 与推理任务，支持 PPO/GRPO 与多轮工具调用。ByteDance's RL training framework for LLM agents and reasoning tasks, with PPO/GRPO and multi-turn tool use.

24.3k stars 4933 forks Python 语言Language Apache-2.0 许可License 最近推送Last push 2026-11-19

为什么选Why choose it

  • 为 Agentic RL 设计，能把工具调用轨迹纳入训练。Designed for Agentic RL; tool-use trajectories can enter training.
  • 与 vLLM/SGLang 推理后端配合，rollout 吞吐高。Works with vLLM/SGLang inference backends for high rollout throughput.
  • 支持多机多卡与异步训练。Supports multi-node, multi-GPU and asynchronous training.

不适合Not for

只做 SFT，不需要这么重的 RL 栈。SFT-only work does not need this heavy RL stack.
环境与奖励设计仍要自己做，框架不替你定义任务。You still design the environment and reward; the framework does not define your task.

最小上手Minimum setup

  1. 从示例环境跑一个单步任务，确认 rollout 与 reward 能通。Run a single-step task from the example environment to verify rollout and reward.
  2. 加一个多轮工具调用任务，记录轨迹长度与失败类型。Add a multi-turn tool-use task and record trajectory length and failure types.
  3. 先在 1 个节点跑通再扩多机，避免一上来调分布式。Get one node working before scaling multi-node; do not debug distributed first.

依赖与成本Dependencies and cost

Python + PyTorch/CUDA；rollout 需要 vLLM/SGLang；多机要 Ray 或 Slurm。Python + PyTorch/CUDA; rollout needs vLLM/SGLang; multi-node needs Ray or Slurm.
