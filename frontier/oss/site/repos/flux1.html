FLUX.1

black-forest-labs / flux

Black Forest Labs 的图像生成模型与推理代码：FLUX.1 [schnell] / [dev] / [pro] 三条线。Black Forest Labs image-generation models and inference code: FLUX.1 [schnell] / [dev] / [pro].

26.1k stars 1933 forks Python 语言Language Apache-2.0 许可License 最近推送Last push 2025-07-31

为什么选Why choose it

  • 开源权重与代码，能本地跑、能微调。Open weights and code; runs locally and can be fine-tuned.
  • 文字渲染与构图能力强，社区 LoRA 生态大。Strong text rendering and composition, with a large community LoRA ecosystem.
  • 提供 ComfyUI / diffusers 接入示例。ComfyUI / diffusers integration examples.

不适合Not for

要免费商用，必须看清权重许可；[dev] 通常是非商用。For free commercial use, read the weight license; [dev] is typically non-commercial.
低显存设备需要量化或 offload，速度会下降。Low-VRAM devices need quantization or offload, which slows generation.

最小上手Minimum setup

  1. 按官方 README 选 [schnell] 或 [dev]，确认权重许可。Follow the official README to pick [schnell] or [dev], and check the weight license.
  2. 用 1024×1024、固定 seed 跑 4 张，记录显存与步数。Generate four 1024×1024 images with a fixed seed; record VRAM and steps.
  3. 接 ComfyUI 或 diffusers，把采样器与 CFG 固定成可复现配方。Wire it into ComfyUI or diffusers and freeze sampler and CFG into a reproducible recipe.

依赖与成本Dependencies and cost

Python + PyTorch/CUDA；显存取决于分辨率与精度；权重需单独下载。Python + PyTorch/CUDA; VRAM depends on resolution and precision; weights are downloaded separately.

许可与使用边界License and usage boundaries

代码 Apache-2.0；权重许可按 [schnell]/[dev]/[pro] 区分，[dev] 非商用，商用前读 BFL 许可原文。Code is Apache-2.0; weight licenses differ across [schnell]/[dev]/[pro]. [dev] is non-commercial — read the BFL license before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.

替代与相邻Alternatives and neighbors

  • ComfyUI — 先试这个Start here，节点式图像/视频生成工作流，把模型、采样、控制网、后处理拼成图。
  • Diffusers — 生产可用Production，扩散模型的 Python 库：pipeline、调度器、训练与量化，适合写代码而不是点界面。

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。Run a small sample first, then decide on production; never start with production data.
