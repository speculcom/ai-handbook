ComfyUI Manager

Comfy-Org / ComfyUI-Manager

ComfyUI 的扩展与模型管理器：装缺失节点、下载模型、检查版本冲突，还能做环境快照与恢复。An extension and model manager for ComfyUI: install missing nodes, download models, check version conflicts and snapshot or restore an environment.

16.9k stars 2626 forks Python 语言Language GPL-3.0 许可License 最近推送Last push 2026-11-20

为什么选Why choose it

  • 打开工作流提示缺节点时，能直接搜、装、重启，不用手动克隆。Finds missing nodes instead of hand-installing dependencies.
  • 能管模型下载与路径，省掉到处找 checkpoint 的时间。Model downloads and version checks are centralised.
  • 快照/恢复对折腾环境的人很实用。Environment snapshots make workflows portable.

不适合Not for

会从 GitHub 等来源装第三方代码，来源与权限要自己审。You run ComfyUI without custom nodes.
它不生产工作流，别把插件数量当能力。You cannot review third-party code before installing it.

最小上手Minimum setup

  1. 把仓库放进 `custom_nodes/`，重启 ComfyUI，确认 Manager 面板出现。Create an environment snapshot before installing anything.
  2. 先装一个官方常用节点，观察依赖装到哪里、是否污染主环境。Install one node and inspect its dependencies.
  3. 生产或共用环境先做快照，再批量装插件。Restore the snapshot and confirm the workflow still loads.

依赖与成本Dependencies and cost

ComfyUI + Python 环境；模型下载还要网络与磁盘。GPU 按工作流而定。Check runtime, model weights and external service dependencies in the README.

代码 GPL-3.0；第三方节点与模型各自许可。Code is GPL-3.0; model weights, training data and generated content may have separate terms — check each before commercial use.
