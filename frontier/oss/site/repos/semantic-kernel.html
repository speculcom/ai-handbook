Semantic Kernel

microsoft / semantic-kernel

微软的跨语言 agent/插件编排框架，覆盖 C#、Python、Java，提供连接器、函数、记忆、流程与 Agent 抽象。Microsoft’s cross-language agent and plugin framework for C#, Python and Java, with connectors, functions, memory, processes and agent abstractions.

28.8k stars 4865 forks C# 语言Language MIT 许可License 最近推送Last push 2026-11-20

为什么选Why choose it

  • 团队在 .NET 或 Java 生态时，它比 Python-only 框架更容易接入现有服务、依赖注入和企业权限。One framework across .NET, Python and Java teams.
  • 插件与函数调用抽象成熟，适合把内部 API 包装成模型可调用的工具。Connectors and plugins map to existing enterprise services.
  • 官方文档和示例完整，适合作为企业落地的保守起点。Process and agent abstractions cover both deterministic and model-driven flows.

不适合Not for

只跑一个 Python demo，框架抽象会显得重。You want a tiny Python-only agent library.
需要极简、单文件 agent 的场景，直接看 smolagents 或 Agno 更轻。You need the newest experimental agent features without a stable API.

最小上手Minimum setup

  1. 按官方 quickstart 安装对应语言包，确认 .NET/Python/Java 版本。Run the official sample in the language your team uses.
  2. 创建一个 Kernel，接一个 chat completion 和一个自定义 plugin 函数。Register one function as a plugin and call it from a prompt.
  3. 把插件换成自己一个只读内部 API，观察函数调用与错误处理。Add a process with a deterministic step and a model step, then test failures.

依赖与成本Dependencies and cost

.NET 8+ / Python 3.10+ / Java 17+；模型 API 或本地端点；企业场景还要身份与日志。Check runtime, model weights and external service dependencies in the README.

许可与使用边界License and usage boundaries

代码 MIT；模型与数据另计。Code is MIT; model weights, training data and generated content may have separate terms — check each before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.

替代与相邻Alternatives and neighbors

  • LangGraph — 生产可用Production，把 agent 写成有状态图：节点、边、检查点、人工确认与回滚都能显式表达。Write an agent as a stateful graph: nodes, edges, checkpoints, human approval and rollback are explicit.
  • Agno — 生产可用Production，轻量高性能的 agent runtime，支持单 agent、团队、workflow，以及 memory、knowledge、tools 和多模态输入。A lightweight, high-performance agent runtime supporting single agents, teams, workflows, memory, knowledge, tools and multimodal input.
  • OpenAI Agents SDK — 先试这个Start here，轻量的 agent 运行时：agent、handoff、guardrail、trace 四个核心概念。A lightweight agent runtime with four core ideas: agents, handoffs, guardrails and traces.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。Run a small sample first, then decide on production; never start with production data.
