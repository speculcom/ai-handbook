语音与音频Speech & Audio生产可用Production

Pipecat

pipecat-ai / pipecat

面向语音与多模态应用的实时管线框架：把 transport、VAD、STT、LLM、TTS 与打断串成可观测的帧流。A realtime pipeline framework for voice and multimodal apps: transport, VAD, STT, LLM, TTS and interruption as an observable frame stream.

— stars — forks — 语言Language BSD-2-Clause 许可License 最近推送Last push —

为什么选Why choose it

  • 帧流模型清楚：每个处理器的输入输出可观测，延迟卡在哪一段容易定位。The frame-stream model is clear: each processor’s input and output are observable, so latency is easy to localise.
  • 传输层可换（WebRTC、WebSocket、电话等），不把业务绑死在一个云。The transport layer is swappable (WebRTC, WebSocket, telephony), so the business is not locked to one cloud.
  • Daily 维护、社区活跃，示例覆盖语音助手、实时视频与多模态。Maintained by Daily with an active community; examples cover voice assistants, realtime video and multimodal.

不适合Not for

只做文本聊天，不需要音频帧与实时打断。Text-only chat does not need audio frames or realtime interruption.
想要托管好的成品客服系统，先看 SaaS；这套要自己接供应商与部署。For a hosted turnkey contact-centre product, look at SaaS; this expects vendor wiring and deployment.

最小上手Minimum setup

  1. 读官方 README / quickstart，确认 Python 版本与系统依赖。Read the official README and quickstart; confirm the runtime version and system dependencies.
  2. 按官方最小示例跑通 本地语音管线，记录端口、密钥与数据路径。Run the smallest local voice pipeline example and record ports, keys and data paths.
  3. 换成自己的 1–2 个样本，观察延迟、并发与失败模式；不要先用生产流量压。Try one or two of your own cases and watch latency, concurrency and failure modes; do not start with production traffic.

依赖与成本Dependencies and cost

Python 运行时 + 至少一家 STT/TTS/LLM 凭据；实时场景要 TURN / WebRTC 与稳定网络。Check runtime, model weights and external service dependencies in the README.

许可与使用边界License and usage boundaries

代码 BSD-2-Clause；Daily 托管、模型与语音供应商另计条款。Code is BSD-2-Clause; model weights, training data and generated content may have separate terms — check each before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.
