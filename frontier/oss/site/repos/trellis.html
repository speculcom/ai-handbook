TRELLIS

microsoft / TRELLIS

微软的 3D 资产生成模型：文本或图片输入，输出辐射场、3D Gaussian 与 mesh；核心是 Structured LATent（SLAT）统一表示与 Rectified Flow Transformer。

14.4k stars 1435 forks Python 语言 MIT 许可 最近推送 2026-10-27

为什么选

  • 一个模型支持多种 3D 输出格式，还能做局部编辑，比只出 mesh 的方案灵活。
  • CVPR 2025 Spotlight，代码与权重开放。
  • SLAT 表示把几何与外观解耦，便于下游导出与再渲染。

不适合

生成的是资产草模，拓扑、UV 与材质仍需美术修。
显存与时间门槛高，不是实时工具。
复杂场景与透明材质仍容易失败。

最小上手

  1. 按 README 用 conda 建环境，下载预训练权重。
  2. 先用一张物体图跑 image-to-3D，导出 mesh 与 Gaussian。
  3. 再试 text-to-3D 与局部编辑，检查面数与纹理。

依赖与成本

Linux + NVIDIA GPU（CUDA）；conda；数 GB 权重；Blender/trimesh 查看输出。

许可与使用边界

代码 MIT；预训练权重与训练数据条款另核，商用前读模型卡。

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。

替代与相邻

  • Hunyuan3D-2 — 规模 / 性能，腾讯混元的 3D 生成模型：图/文生 3D mesh，两阶段 shape + texture，支持轻量版与 PBR 纹理。
  • Qwen-Image — 规模 / 性能，Qwen 的图像生成与编辑模型，20B MMDiT，主打复杂中文文字渲染、海报排版和多图编辑。
  • Open-Sora — 规模 / 性能，开源视频生成全流程：数据清洗、VAE、DiT 训练、推理，支持文生视频与图生视频。

下一步

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。
