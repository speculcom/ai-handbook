OpenAI Agents SDK

openai / openai-agents-python

轻量的 agent 运行时：agent、handoff、guardrail、trace 四个核心概念。A lightweight agent runtime with four core ideas: agents, handoffs, guardrails and traces.

30.8k stars 5075 forks Python 语言Language MIT 许可License 最近推送Last push 2026-11-19

为什么选Why choose it

  • 概念少，代码结构清楚，适合从零写一个可维护的 agent。Small API surface; the agent loop and handoff model are easy to inspect.
  • handoff 与 guardrail 把多 agent 交接和安全边界做成显式 API。Guardrails and tracing are built in rather than left to the application.
  • trace 能接 OpenAI 平台，也支持其他模型。Works across model providers and can be extended with tools.

不适合Not for

需要复杂图状态与持久化，LangGraph 更合适。You need a full visual workflow builder or a hosted agent platform.
只想要平台化托管，应该看工具站里的托管产品。You require a complex multi-agent graph with persistent state out of the box.

最小上手Minimum setup

  1. 读 README / quickstart，确认 运行时 版本与系统依赖。Install the SDK and run the official hello-world agent.
  2. 按官方示例跑最小用例，记录模型/权重、密钥与数据路径。Add one tool and one handoff, then inspect the trace.
  3. 换成自己的 1–2 个样本，观察日志、显存/内存与失败模式。Add a guardrail that rejects an unsafe tool call and confirm the failure path.

依赖与成本Dependencies and cost

Python / Node 运行时 + LLM API 密钥；浏览器类还要 Playwright/Chromium；生产要并发、日志与重试。Check runtime, model weights and external service dependencies in the README.

替代与相邻Alternatives and neighbors

  • LangGraph — 生产可用Production，把 agent 写成有状态图：节点、边、检查点、人工确认与回滚都能显式表达。Write an agent as a stateful graph: nodes, edges, checkpoints, human approval and rollback are explicit.
  • Pydantic AI — 轻量Lightweight，用 Pydantic 的类型系统写 agent：输入、输出、工具参数都强类型校验。Write agents with Pydantic’s type system: inputs, outputs and tool arguments are strongly validated.
  • smolagents — 轻量Lightweight，Hugging Face 的极简 agent 库，主打“让模型写代码来调用工具”。Hugging Face’s minimal agent library, centred on letting the model write code to call tools.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。Run a small sample first, then decide on production; never start with production data.
