SD.Next

vladmandic / sdnext

Stable Diffusion WebUI 的现代分支，支持新模型、Diffusers/ONNX/OpenVINO 多后端，也兼顾 AMD 与 Intel。A modern fork of Stable Diffusion WebUI supporting new models, Diffusers/ONNX/OpenVINO backends and AMD or Intel hardware.

7.4k stars 582 forks Python 语言Language Apache-2.0 许可License 最近推送Last push 2026-11-20

为什么选Why choose it

  • 新模型跟得快，Flux/SD3 等支持通常比原版 WebUI 早。Multiple backends beyond CUDA.
  • 多后端与多厂商 GPU 支持，非 NVIDIA 用户友好。Supports AMD and Intel accelerators.
  • 保留 WebUI 操作习惯，迁移成本低。Keeps the familiar WebUI surface.

不适合Not for

插件生态与教程仍不如 AUTOMATIC1111 原版。You need the most conservative, widely tested UI.
更新快，偶发回归；生产出图要锁版本。Your GPU backend is unsupported.

最小上手Minimum setup

  1. 按 wiki 选对应 GPU 的启动脚本，先出 512–1024 一张图。Start with the backend that matches your GPU.
  2. 换一个模型与采样器，确认 VAE、精度与显存设置。Render one image and record backend and dtype.
  3. 批量或视频任务再调后端与优化开关，不要一次全开。Compare output with the same seed on a second backend.

依赖与成本Dependencies and cost

Python/PyTorch；NVIDIA/AMD/Intel GPU 均可，按后端装对应运行时；模型权重与 VAE。Check runtime, model weights and external service dependencies in the README.

许可与使用边界License and usage boundaries

代码 Apache-2.0；模型权重与扩展各自许可。Code is Apache-2.0; model weights, training data and generated content may have separate terms — check each before commercial use.

替代与相邻Alternatives and neighbors

  • Stable Diffusion WebUI — 先试这个Start here，最经典的 SD 图形界面，文生图、图生图、LoRA、ControlNet 都在一个页面。The classic Stable Diffusion web UI: text-to-image, image-to-image, LoRA and ControlNet on one page.
  • ComfyUI — 先试这个Start here，节点式图像/视频生成工作流，把模型、采样、控制网、后处理拼成图。A node-based image and video generation workflow that wires models, samplers, ControlNet and post-processing into a graph.
  • InvokeAI — 生产可用Production，面向创作者的图像生成工作台，统一画布、图层、模型管理与批量生成。A creator-oriented image generation workbench with a unified canvas, layers, model management and batch generation.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
