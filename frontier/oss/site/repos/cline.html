Cline

cline / cline

VS Code 内的 autonomous coding agent，能读文件、改代码、跑终端命令、用浏览器，并在每步请求确认。An autonomous coding agent inside VS Code that can read files, edit code, run terminal commands and use a browser, asking for approval at each step.

71.8k stars 7951 forks TypeScript 语言Language Apache-2.0 许可License 最近推送Last push 2026-11-19

为什么选Why choose it

  • 把 plan/act、diff 审阅、命令审批做成可见的 GUI 流程，适合观察人机协作边界。Step-by-step approval keeps a human in the loop.
  • 开源且支持多家模型，方便比较同一任务下不同模型的工具调用质量。Editor integration makes diffs and file context visible.
  • 对本地项目友好，不需要把代码上传到托管服务。Terminal and browser access cover more than code completion.

不适合Not for

纯终端、CI 或远程无头环境；它是 IDE 插件形态。You want fully unattended execution with no approvals.
不愿授予工作区写权限或终端执行权限的用户。You cannot install a VS Code extension or grant workspace access.

最小上手Minimum setup

  1. 在 VS Code 安装 Cline 扩展，配置模型端点。Open a disposable workspace and start with read-only tasks.
  2. 打开一个测试仓库，让它完成一个小改动并逐步确认命令。Approve one file edit and inspect the diff.
  3. 检查每步 diff 与终端输出，记录误改/越权点再决定是否放开自动批准。Run a test command and check the approval prompt before enabling auto-approve.

依赖与成本Dependencies and cost

VS Code 1.84+；模型 API 或本地端点；需要工作区读写与终端权限。Check runtime, model weights and external service dependencies in the README.

许可与使用边界License and usage boundaries

代码 Apache-2.0；模型与数据另计。Code is Apache-2.0; model weights, training data and generated content may have separate terms — check each before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.

替代与相邻Alternatives and neighbors

  • OpenHands — 生产可用Production，能读代码、改代码、跑命令的软件工程 agent，提供 CLI、Web 界面与沙箱运行时，可接本地或云端模型。A software-engineering agent that can read code, edit it and run commands, with CLI, web UI and a sandboxed runtime.
  • OpenCode — 生产可用Production，终端里的开源 coding agent：build / plan 双 agent、LSP 反馈、75+ 模型提供商，另有桌面 beta。An open-source coding agent in the terminal: separate build and plan agents, LSP feedback, 75+ model providers and a desktop beta.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
