Google ADK

google / adk-python

Google 的代码优先 Python agent 工具包：把工具、会话、记忆、评测与部署放进同一套抽象，可用 Gemini 或其它模型。

22.3k stars 4397 forks Python 语言 Apache-2.0 许可 最近推送 2026-11-20

为什么选

  • 官方维护，文档与样例完整，适合从单 agent 走到多 agent 编排。
  • 工具体系与 Google 生态（Vertex AI、Gemini）衔接紧，鉴权与部署路径清楚。
  • 同一套代码可本地跑、可上 Cloud Run，原型到上线的落差小。

不适合

不是低代码拖拽平台，要写 Python。
部分托管与评测能力绑定 Google Cloud，换云要自己接。
框架抽象较完整，深度定制前先读源码，别把黑盒当标准。

最小上手

  1. pip install google-adk，按 quickstart 建一个带单个 tool 的 agent。
  2. 用 adk web 本地跑一轮，观察 tool call、session 与事件流。
  3. 再把 agent 拆成 sub-agents，确认路由、状态与错误处理。

依赖与成本

Python 3.10+；Gemini API key 或其它模型接入；部署到 Cloud Run 需要 GCP 配置。

许可与使用边界

Apache-2.0；示例数据、第三方工具与 Google 托管服务各自条款。

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。

替代与相邻

  • LangGraph — 生产可用，把 agent 写成有状态图：节点、边、检查点、人工确认与回滚都能显式表达。
  • OpenAI Agents SDK — 先试这个，轻量的 agent 运行时：agent、handoff、guardrail、trace 四个核心概念。
  • Pydantic AI — 轻量，用 Pydantic 的类型系统写 agent：输入、输出、工具参数都强类型校验。

下一步

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。
