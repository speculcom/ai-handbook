Goose

block / goose

Block 开源的本地 AI agent，提供 CLI 与桌面端，通过 MCP 扩展工具，可接任意 LLM。Block’s open-source local AI agent with CLI and desktop apps, MCP-based tool extension and support for any LLM.

56.8k stars 6631 forks Rust 语言Language Apache-2.0 许可License 最近推送Last push 2026-11-20

为什么选Why choose it

  • 把 agent 当本地操作助手而不是聊天框：能读文件、跑命令、调 MCP 工具，扩展方式统一。Local-first execution with desktop and CLI surfaces.
  • 桌面端和 CLI 共用一套扩展模型，适合观察本地 agent 的权限与审计设计。MCP extensions avoid a proprietary tool format.
  • 开源实现完整，适合改造为企业内部受控 agent。Model-agnostic, so you can use hosted or local models.

不适合Not for

需要集中式沙箱、多人权限和审计的生产环境，仍要自己做隔离。You need a hosted multi-user platform.
不愿意让 agent 接触本地文件和命令的用户。You cannot manage local tool permissions and updates.

最小上手Minimum setup

  1. 按 README 安装 CLI 或桌面版，配置模型 provider。Install the CLI and run a read-only task.
  2. 接一个只读 MCP server，让它列目录/查文档。Add one MCP server and inspect the tools it exposes.
  3. 在测试目录里跑一个会写文件的任务，观察权限提示与日志。Test a denied permission and confirm the agent stops.

依赖与成本Dependencies and cost

macOS/Linux/Windows；模型 API 或本地端点；MCP server 可选。Check runtime, model weights and external service dependencies in the README.

许可与使用边界License and usage boundaries

代码 Apache-2.0；模型、MCP 工具与数据另计。Code is Apache-2.0; model weights, training data and generated content may have separate terms — check each before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.
