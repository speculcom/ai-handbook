Goose

block / goose

Block 开源的本地 AI agent，提供 CLI 与桌面端，通过 MCP 扩展工具，可接任意 LLM。

56.8k stars 6631 forks Rust 语言 Apache-2.0 许可 最近推送 2026-11-20

为什么选

  • 把 agent 当本地操作助手而不是聊天框：能读文件、跑命令、调 MCP 工具，扩展方式统一。
  • 桌面端和 CLI 共用一套扩展模型，适合观察本地 agent 的权限与审计设计。
  • 开源实现完整，适合改造为企业内部受控 agent。

不适合

需要集中式沙箱、多人权限和审计的生产环境，仍要自己做隔离。
不愿意让 agent 接触本地文件和命令的用户。

最小上手

  1. 按 README 安装 CLI 或桌面版，配置模型 provider。
  2. 接一个只读 MCP server，让它列目录/查文档。
  3. 在测试目录里跑一个会写文件的任务，观察权限提示与日志。

依赖与成本

macOS/Linux/Windows；模型 API 或本地端点；MCP server 可选。

许可与使用边界

代码 Apache-2.0；模型、MCP 工具与数据另计。

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。

替代与相邻

  • OpenClaw — 先试这个，把个人助理跑在自己机器上，接入 20+ 聊天渠道与原生桌面/移动端；一个 Gateway 管理会话、技能、定时任务和沙箱执行。
  • OpenHands — 生产可用，能读代码、改代码、跑命令的软件工程 agent，提供 CLI、Web 界面与沙箱运行时，可接本地或云端模型。
  • Cline — 先试这个，VS Code 内的 autonomous coding agent，能读文件、改代码、跑终端命令、用浏览器，并在每步请求确认。

下一步

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。
