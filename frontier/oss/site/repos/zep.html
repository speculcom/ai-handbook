Zep

getzep / zep

面向 agent 的记忆服务：会话摘要、事实抽取、图记忆与检索，提供社区版和云服务。

5.0k stars 658 forks Python 语言 Apache-2.0 许可 最近推送 2026-11-17

为什么选

  • 把会话历史压缩成摘要 + 事实 + 图关系，减少上下文膨胀。
  • 有现成的服务端与 SDK，适合快速给 agent 接记忆。
  • 社区版可自部署，便于先做内网验证。

不适合

只需要短期对话缓存，用普通上下文窗口就够。
把图记忆当知识图谱产品；它更偏会话记忆。

最小上手

  1. 用 Docker Compose 起社区版，按 quickstart 写入一段会话。
  2. 再开一个新会话，验证摘要与事实能否被检索。
  3. 检查删除/过期接口，确认用户数据可撤回。

依赖与成本

Docker / Python；自部署要 Postgres、向量库与 LLM API；云版按套餐。

许可与使用边界

代码 Apache-2.0；云服务与社区版的数据处理条款分开核对。

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。

替代与相邻

  • Mem0 — 生产可用，给 agent 加长期记忆层：抽取、存储、检索用户偏好与事实，支持向量/图存储后端。
  • LangGraph — 生产可用，把 agent 写成有状态图：节点、边、检查点、人工确认与回滚都能显式表达。
  • RAGFlow — 先试这个，带文档解析、切分、检索与引用的 RAG 平台，适合把一套知识库跑起来。

下一步

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。
