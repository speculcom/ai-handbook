Stable Diffusion 系模型的训练 GUI 与脚本集合：LoRA、DreamBooth、fine-tune、数据集打标与工具，覆盖 SD1/SDXL/FLUX 等。A training GUI and script collection for Stable Diffusion models: LoRA, DreamBooth, fine-tuning, dataset tagging and utilities across SD1, SDXL and FLUX.

12.7k stars 1610 forks Python 语言Language Apache-2.0 许可License 最近推送Last push 2026-08-01

为什么选Why choose it

  • GUI 把复杂训练参数摊开，适合个人与小队做角色/风格 LoRA。Covers several fine-tuning methods in one toolkit.
  • 脚本成熟，社区教程多，能和 ComfyUI 工作流衔接。Dataset tagging utilities reduce manual work.
  • 支持多种基础模型与训练方式，迁移成本低。Supports SD1, SDXL and FLUX lines.

不适合Not for

不是一键出图产品；数据清洗、打标与参数调试决定结果。You need a hosted training service.
训练吃显存与时间，云 GPU 成本要算。You cannot curate and license a training dataset.
GUI 封装会隐藏细节，出问题仍要读日志与脚本。GUI 封装会隐藏细节，出问题仍要读日志与脚本。

最小上手Minimum setup

  1. 按 README 装 venv 与依赖，启动 gui.py。Train a small LoRA on 10 licensed images.
  2. 准备 20-50 张同主体图，用 WD14 打标。Compare the same seed before and after training.
  3. 先跑一个低步数 LoRA，固定 seed 对比基模，确认过拟合前停。Check overfitting on a held-out prompt.

依赖与成本Dependencies and cost

Python + PyTorch/CUDA；NVIDIA GPU（8GB 起，越大越稳）；训练图片与正则图；可选 wandb/tensorboard。Check runtime, model weights and external service dependencies in the README.
