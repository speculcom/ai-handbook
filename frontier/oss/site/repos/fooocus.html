多模态与图像视频轻量

Fooocus

lllyasviel / Fooocus

把 SDXL 的常用参数收起来，主打“少调参也能出好图”。

54.0k stars 8623 forks Python 语言 GPL-3.0 许可 最近推送 2025-12-01

为什么选

  • 界面简单，默认参数就能用。
  • 内置风格与质量优化，适合新手。
  • 本地部署，显存要求相对友好。

不适合

需要复杂控制网与批量流水线，ComfyUI 更合适。
项目更新节奏慢，模型支持有限。

最小上手

  1. 读 README / quickstart，确认 运行时 版本与系统依赖。
  2. 按官方示例跑最小用例，记录模型/权重、密钥与数据路径。
  3. 换成自己的 1–2 个样本，观察日志、显存/内存与失败模式。

依赖与成本

通常需要 GPU（10–24GB+ 视模型而定）与模型权重；视频任务还要解码、存储与更长生成时间。

许可与使用边界

代码许可为 仓库 LICENSE；模型权重、训练数据与生成内容可能另有条款，商用前逐项核对。

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。

替代与相邻

  • ComfyUI — 先试这个，节点式图像/视频生成工作流，把模型、采样、控制网、后处理拼成图。
  • Stable Diffusion WebUI — 先试这个，最经典的 SD 图形界面，文生图、图生图、LoRA、ControlNet 都在一个页面。
  • InvokeAI — 生产可用，面向创作者的图像生成工作台，统一画布、图层、模型管理与批量生成。

下一步

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。
