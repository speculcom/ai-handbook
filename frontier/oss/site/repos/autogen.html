AutoGen

microsoft / autogen

微软的多 agent 框架，强调可对话的 agent、工具调用与分布式运行。Microsoft’s multi-agent framework built around conversable agents, tool use and distributed execution.

61.9k stars 9412 forks Python 语言Language CC-BY-4.0 许可License 最近推送Last push 2026-11-12

为什么选Why choose it

  • 多 agent 对话与协作抽象成熟，适合研究型与复杂任务。Conversable agents make multi-agent patterns such as group chat and critic loops explicit.
  • 支持代码执行、工具调用与多种运行时。Tool use and code execution are first-class, not bolted on.
  • 文档和论文多，便于理解设计取舍。Supports distributed runtimes and multiple model providers.

不适合Not for

版本迭代快，接口变化需要跟。You want the smallest possible single-agent loop with no conversation model.
轻量单 agent 任务会显得重。You need a stable, fully deterministic workflow with no free-form agent chat.

最小上手Minimum setup

  1. 读 README / quickstart，确认 运行时 版本与系统依赖。Use the official quickstart and a single model provider first.
  2. 按官方示例跑最小用例，记录模型/权重、密钥与数据路径。Run a two-agent conversation and log every turn and tool call.
  3. 换成自己的 1–2 个样本，观察日志、显存/内存与失败模式。Add a termination condition and a budget cap before trying code execution.

依赖与成本Dependencies and cost

Python / Node 运行时 + LLM API 密钥；浏览器类还要 Playwright/Chromium；生产要并发、日志与重试。Check runtime, model weights and external service dependencies in the README.

替代与相邻Alternatives and neighbors

  • LangGraph — 生产可用Production，把 agent 写成有状态图：节点、边、检查点、人工确认与回滚都能显式表达。Write an agent as a stateful graph: nodes, edges, checkpoints, human approval and rollback are explicit.
  • CrewAI — 先试这个Start here，用“角色 + 任务 + 协作流程”搭多 agent 团队，适合快速把分工跑起来。Build multi-agent teams from roles, tasks and a collaboration process; good for getting division of labour running quickly.
  • OpenAI Agents SDK — 先试这个Start here，轻量的 agent 运行时：agent、handoff、guardrail、trace 四个核心概念。A lightweight agent runtime with four core ideas: agents, handoffs, guardrails and traces.

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • 用一个小样本跑通，再决定是否进生产；不要直接上生产数据。Run a small sample first, then decide on production; never start with production data.
