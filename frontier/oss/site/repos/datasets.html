Datasets

huggingface / datasets

Hugging Face 的数据集库：load_dataset 读取 Hub、Parquet、JSON、CSV，支持流式读取、内存映射、map/filter/shuffle 与 train/test split，不用先把整份语料塞进内存。Hugging Face’s dataset library: load_dataset reads Hub, Parquet, JSON and CSV with streaming, memory mapping, map/filter/shuffle and train/test splits — without loading the whole corpus into RAM.

22.2k stars 3674 forks Python 语言Language Apache-2.0 许可License 最近推送Last push 2026-11-19

为什么选Why choose it

  • 一行读取 Hub 数据集，版本与 schema 有记录。One line loads a Hub dataset with a recorded version and schema.
  • 流式与内存映射让大语料在笔记本上也能处理。Streaming and memory mapping make large corpora workable on a laptop.
  • 和 Transformers、Accelerate、PEFT 的训练循环直接衔接。Plugs directly into Transformers, Accelerate and PEFT training loops.

不适合Not for

不是数据治理平台；许可、PII 与去重仍要自己审。Not a data-governance platform; licence, PII and deduplication remain your responsibility.
超大语料需要流式或分片，随机访问会变慢。Very large corpora need streaming or sharding; random access gets slower.
复杂标注工作流应接 Argilla / Label Studio。Complex annotation workflows belong in Argilla or Label Studio.

最小上手Minimum setup

  1. pip install datasets，先 load_dataset 一个小型文本数据集。pip install datasets and load a small text dataset first.
  2. 检查字段、split 与许可证，再做 map/filter 和 tokenizer。Inspect fields, splits and licence, then map/filter and tokenize.
  3. 大语料改用 streaming=True，测一遍吞吐与磁盘占用。For large corpora use streaming=True and measure throughput and disk use.

依赖与成本Dependencies and cost

Python；Hub 访问需要网络；Parquet/Arrow 依赖内置；大规模处理需要磁盘与内存预算。Python; network for Hub access; Parquet/Arrow support is built in; large jobs need disk and RAM budget.

许可与使用边界License and usage boundaries

代码 Apache-2.0；每个数据集有自己的许可与使用条款，商用前读 dataset card。Code is Apache-2.0; every dataset has its own licence and terms — read the dataset card before commercial use.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.
