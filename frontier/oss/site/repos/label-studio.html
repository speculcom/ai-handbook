Label Studio

HumanSignal / label-studio

多模态数据标注平台：文本、图像、音频、视频、HTML 与时间序列都能用模板化界面标注；支持 ML 后端预标注、多人协作与多种导出格式。A multimodal data-labeling platform: text, image, audio, video, HTML and time series with templated interfaces; ML-backend pre-labeling, multi-user collaboration and many export formats.

28.7k stars 3801 forks Python 语言Language Apache-2.0 许可License 最近推送Last push 2026-11-20

为什么选Why choose it

  • 一个界面覆盖多数模态，省去多套标注工具。One interface covers most modalities, avoiding several annotation tools.
  • ML 后端可以把模型预测变成预标注。An ML backend turns model predictions into pre-labels.
  • 导出格式多，接训练管线直接。Many export formats plug straight into training pipelines.

不适合Not for

开源版与企业版功能不同，商用前读条款。Community and enterprise editions differ — read the terms before commercial use.
复杂权限、审计、SSO 与 SLA 通常要企业版。Complex permissions, audit, SSO and SLAs usually require enterprise.
不是数据治理或隐私合规平台。Not a data-governance or privacy-compliance platform.

最小上手Minimum setup

  1. 用 Docker 起 Label Studio，建一个项目并选标注模板。Start Label Studio with Docker, create a project and pick a labeling template.
  2. 导入十几条样本，配一个 ML backend 做预标注。Import a dozen samples and connect an ML backend for pre-labeling.
  3. 导出 JSON/CoNLL，检查字段是否与训练代码对齐。Export JSON/CoNLL and check fields match the training code.

依赖与成本Dependencies and cost

Docker / Python；生产要 Postgres 与对象存储；ML backend 要一个模型服务。Docker / Python; production wants Postgres and object storage; ML backend needs a model service.

许可与使用边界License and usage boundaries

开源版 Apache-2.0；企业功能与托管服务另有商业条款，商用前核对。Community edition is Apache-2.0; enterprise features and hosted service have commercial terms.

开源不等于可商用：GPL / AGPL 有传染性；代码许可、模型许可、生成内容许可要分开看。上线前读仓库 LICENSE 与模型卡，必要时让法务确认。Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.

替代与相邻Alternatives and neighbors

  • Argilla — 生产可用Production，人机协同的数据标注与 curation 平台：数据集、标注任务、弱监督、模型反馈与 Hugging Face Hub 集成，适合 SFT/RLHF 数据。Human-in-the-loop data annotation and curation: datasets, labeling tasks, weak supervision, model feedback and Hugging Face Hub integration for SFT/RLHF data.
  • Docling — 先试这个Start here，文档解析工具包：PDF / HTML / Office 转结构化 Markdown / JSON，保留版面、表格与阅读顺序。
  • Unstructured — 生产可用Production，文档 ETL 工具：把 PDF、HTML、图片、Office 文件分区、清洗并带上元数据，喂给 RAG。

下一步Next steps

  • 打开 GitHub，先读 README、LICENSE、最近 release 与 issue。Open GitHub and read the README, LICENSE, latest release and issues first.
  • 按“部署依赖 / 显存 / 数据 / 网络 / 权限”列一张上手清单。Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
