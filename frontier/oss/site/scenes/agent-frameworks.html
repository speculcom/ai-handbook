Agent 框架与编排Agent Frameworks & Orchestration

把模型、工具、状态和人工确认串成一条可执行、可恢复的流程。先想清楚要不要状态机，再决定用哪一层抽象。Wire models, tools, state and human approval into a workflow that can run, retry and resume. Decide whether you need a state machine before choosing an abstraction.

怎么选How to choose

• 流程有分支、重试、人工确认：先看 LangGraph。Branches, retries and human approval: start with LangGraph.
• 第一次搭多 agent、想快速跑分工：CrewAI 更直观。First multi-agent setup with quick role division: CrewAI is easier to grasp.
• 想要类型安全、长期维护：Pydantic AI；想要极简代码执行：smolagents。Type safety and long maintenance: Pydantic AI; minimal code execution: smolagents.
不适合：Not for: 不要为了“多 agent”而多 agent。很多任务一个模型加两个工具就够。Do not add multiple agents just for the label. Many tasks need one model and two tools.
