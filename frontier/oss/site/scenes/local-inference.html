OSS · Scene 03

本地推理与部署

从单机一条命令，到多卡高吞吐服务，差的是批处理、显存、量化和运维。先按并发与延迟选层，不要一上来就上集群。

看这个场景的全部 → 并排对比前 3 个 回首页
6个场景精选
适合想把模型跑在自己机器、内网或自有 GPU 上的人；只用 API 的不需要这一节。适合谁

怎么选

• 第一次本地跑：Ollama。
• Mac / CPU / 边缘：llama.cpp。
• 生产高吞吐：vLLM 或 SGLang；HF 生态：TGI。
不适合：本地跑不等于免费。显存、电费、运维和模型更新都要算。
