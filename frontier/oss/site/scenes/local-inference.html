OSS · Scene 03

本地推理与部署Local Inference & Serving

从单机一条命令，到多卡高吞吐服务，差的是批处理、显存、量化和运维。先按并发与延迟选层，不要一上来就上集群。Run models on hardware you control: check quantisation, memory fit, concurrency and serving API before choosing.

15个场景精选selected repos
适合想把模型跑在自己机器、内网或自有 GPU 上的人；只用 API 的不需要这一节。For privacy-sensitive work, offline use or predictable long-running cost.适合谁Who it is for

怎么选How to choose

• 第一次本地跑：Ollama。First local run: Ollama; production serving: vLLM or SGLang.
• Mac / CPU / 边缘：llama.cpp。Mac or small VRAM: check quantised formats and unified memory.
• 生产高吞吐：vLLM 或 SGLang；HF 生态：TGI。Measure tokens/s and time-to-first-token on your own workload.
不适合：Not for: 本地跑不等于免费。显存、电费、运维和模型更新都要算。Do not assume a 7B model replaces a frontier model on hard reasoning.
