来源标识Provenance

TEE 远程证明（以 Phala 为例）TEE remote attestation (Phala example)

交集：AI 推理跑在第三方云上时，用户怎么相信「模型与代码确实按声明运行」。TEE 远程证明把运行时度量、签名与验证报告交给软件核验。
适用范围：这里以 Phala 的 CPU/GPU TEE 与 attestation 示例说明流程；它不保证模型本身正确，也不保证所有云都支持同样的证明格式。
未解决：不同 TEE 厂商（Intel TDX / NVIDIA CC / AMD SEV）证明链与信任根不统一；侧信道、供应链与运维方仍可能破坏假设；跨云验证缺少统一标准。Intersection: when AI inference runs on a third-party cloud, how does the user know the model and code ran as claimed? TEE remote attestation exposes runtime measurements, signatures and verifier reports to software.
Scope: this uses Phala's CPU/GPU TEE and attestation example to show the flow; it does not guarantee the model is correct, nor that every cloud supports the same attestation format.
Open: trust roots and attestation chains differ across Intel TDX / NVIDIA CC / AMD SEV; side channels, supply chain and operators can still break the assumption; cross-cloud verification lacks a common standard.
