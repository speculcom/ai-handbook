支付与结算Payments & settlement

Coinbase CDP：AgentKit、x402 Facilitator 与 Agentic AccountCoinbase CDP: AgentKit, the x402 facilitator and Agentic Accounts

问题：Agent 需要一个能自己收付稳定币的钱包与结算通道，但直接暴露私钥或让模型自由转账都不安全。
证据位置：CDP 提供 AgentKit（给 agent 钱包与链上动作）、x402 Facilitator（验证并结算 402 付款）与 Coinbase for Agents（受限额约束的账户连接）。官方 FAQ 说 facilitator 已在 Base、Polygon、Arbitrum、Monad、World、Solana 主网结算，并做合规筛查。
边界：AgentKit 官方 README 明确说 SDK 不做转账人工审批、消费上限或地址白名单，这些要开发者自己加；100 million 交易是平台口径，不是独立审计。
未解决：私钥/助记词托管、制裁筛查的误报、跨链最终性与退款仍要按部署方案处理。Problem: agents need a wallet and settlement rail for stablecoins, but exposing private keys or letting a model transfer funds freely is unsafe.
Where the evidence sits: CDP provides AgentKit (wallets and on-chain actions), an x402 facilitator (verify and settle 402 payments) and Coinbase for Agents (a scoped account connection). The official FAQ says the facilitator settles on Base, Polygon, Arbitrum, Monad, World and Solana mainnets and screens every payment.
Boundary: AgentKit’s own README says the SDK does not gate transfers behind human approval, enforce spend caps or allowlist destinations; developers must add those. The 100 million transaction figure is a platform statement, not an independent audit.
Unresolved: key custody, sanctions false positives, cross-chain finality and refunds still depend on the deployment.
