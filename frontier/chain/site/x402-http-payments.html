支付与结算Payments & settlement

x402：用 HTTP 402 直接为 API 付费x402: paying for APIs over HTTP 402

交集：把「按次付费」放回 HTTP 语义里——服务端返回 402 与付款指令，客户端付完再取资源，不需要账号、会话或凭据管理。对 AI Agent 的意义是工具调用可以自带预算：Agent 调一个付费 API，付款与取数在同一个请求链路里完成。
适用范围：官方文档把流程写成五步（请求、402 指令、付款载荷、服务端或 facilitator 验证结算、返回资源），并说明标准本身 0 费用、支持 EVM 批量结算。
未解决：付款的最终性、退款、争议与合规责任落在具体服务方与链上资产，不在协议层；本站不评价任何 x402 服务的定价或可靠性。The intersection: putting pay-per-call back into HTTP semantics — the server returns 402 plus payment instructions, the client pays, then receives the resource, with no accounts, sessions or credential management. For AI agents this means tool calls can carry their own budget: a paid API call and its payment settle in the same request path.
Scope: the official docs describe a five-step flow (request, 402 instructions, payment payload, verification and settlement by the server or a facilitator, resource) and state that the standard itself has zero fees and supports batched EVM settlement.
Open: finality, refunds, disputes and compliance sit with the specific service and on-chain asset, not the protocol layer; this entry does not judge any x402 service’s pricing or reliability.
