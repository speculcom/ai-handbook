怎么用这个站How to use this site

先挑一个类目，点开卡片看关键参数；想深读就进条目页。每条都链到官网，拿不准的地方直接回原文核对。Pick a category, scan the key specs, then open an entry for the full note. Every entry links to the official page; when something is unclear, go back to the source.

  • 只写官网、规格书、协议原文或论文里能查到的东西；查不到的会标出来。We only write what can be found in official docs, datasheets, protocol text or papers; anything missing is marked as such.
  • 同一个数字可能因为测试条件不同而变化，页面会尽量写清条件。The same number can change with test conditions; the page says what it can about the setup.
