The software stack is AWS Neuron, not CUDA, so migration cost is a separate line item. The page does not list per-chip HBM for Trainium2, so this card leaves it blank rather than guessing; Trainium3 on the same page is a different generation (144 GB HBM3e, 4.9 TB/s).
