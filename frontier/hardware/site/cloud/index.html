云 GPU 怎么比价：先统一口径

不要拿“每卡每小时”直接横比。整机起租、存储、出网、冷启动、可用性和合同期，都会把真实单价抬高或压低。

指南

按秒、包月、预留：怎么选计费方式

计费方式不是折扣问题，是任务形态问题。短任务、稳定推理、长期训练的答案不一样。

指南

存储与出网：最容易被忽略的两笔钱

GPU 小时价只是账单的一部分。模型权重、数据集、日志、镜像和出网流量，常常在月末把预算翻一倍。

指南

合规与数据驻留：先定数据能去哪

云 GPU 选型不只是价格。数据能不能出境、能不能给第三方处理、出了事谁负责，要在签合同前写清。
