回答「桌面级四机集群能做什么」。四台 DGX Spark 用 ConnectX-7 直接成环，不经过交换机；合计 512GB 统一内存、16TB NVMe，官方口径可在 FP4 下跑最多 700B 参数模型（示例点名 DeepSeek V4.1）。适合在桌面上调试多机科学计算与 Agent 工作流，再上大集群；不是替代共享 GPU 集群的生产设施。Answers what a four-node desktop cluster can do. Four DGX Spark units link directly in a ring over ConnectX-7 without a switch, pooling 512GB of unified memory and 16TB of NVMe; NVIDIA says up to 700B-parameter models fit at NVFP4 (it names DeepSeek V4.1 as an example). It is built for debugging multi-node scientific and agent workloads at a desk before moving to a larger cluster, not as a production replacement for a shared GPU cluster.
