回答「Mac Studio 这代能把多大的模型放进内存」。M5 Ultra 是 Apple 首款四晶粒芯片：最多 36 核 CPU、80 核 GPU（每核带神经网络加速器）、32 核神经引擎，最高 512GB 统一内存、1.2TB/s 带宽，官方称可完全在端侧跑数千亿参数模型。它不是 CUDA 生态，训练与推理框架支持取决于 MLX / Metal / Core ML；适合本地大内存推理与创作，不适合替代多卡 HBM 服务器。Answers how large a model the current Mac Studio can hold in memory. M5 Ultra is Apple’s first four-die chip: up to a 36-core CPU, an 80-core GPU with a neural accelerator in each core, a 32-core Neural Engine, up to 512GB of unified memory and 1.2TB/s of bandwidth; Apple says it can run hundreds-of-billions-parameter models entirely on-device. It is not a CUDA platform, so training and inference support depends on MLX / Metal / Core ML; it fits large-memory local inference and creation, not a multi-GPU HBM server.
