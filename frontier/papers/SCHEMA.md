# 论文 · 内容规范

真相源：`entries.json`。本站做**研究级论文卡**，`learn` 站的 `kind: paper` 微型指南保留作入门解读，两边双向链接、不迁移、不复制结论。

## 卡片四段（固定，缺一不可）

| 段 | 写什么 |
|---|---|
| 问题 | 这篇论文想解决的具体问题，用一句话说清，不写领域宏大叙事 |
| 证据位置 | 结论出现在哪一节、哪张表、哪个实验设置；给 arXiv 或官方 PDF 的原文短句 |
| 作者自陈局限 | 论文自己写明的限制条件（数据范围、算力、未覆盖场景），引原文 |
| 它没主张的 | 明确写出容易被转述夸大的部分：论文没证明什么、没比较什么 |

另加复现状态：**落在 `specs` 的 `复现状态 / reproduction` 键里**，默认写 `未复现`；只有真跑过才写环境与日期，且不得把「读代码」当成复现。

## 条目字段

| 字段 | 类型 | 要求 |
|---|---|---|
| `id` | 字符串 | 建议 arXiv 编号或作者年份短名，全站唯一 |
| `title` | `{zh, en}` | 双语标题，英文用论文原题；中文栏同样放原题（本站不译论文标题） |
| `category` | 字符串 | 方法谱系归属，取值集中在六类：`architecture` / `scaling` / `adaptation` / `alignment` / `efficiency` / `reasoning`。新增类目要同时更新谱系页口径 |
| `url` | URL | arXiv 摘要页、官方 PDF 或会议论文集页面 |
| `license` | 对象 | `kind` / `spdx`、`evidenceUrl`、`checkedAt`；arXiv 预印本用 `kind: arxiv-preprint` |
| `evidence` | 数组 | 每条含 `url` 与 `quote`，引原文而非二手转述；至少一条支撑核心主张、至少一条来自作者自陈局限或讨论 |
| `notes` | `{zh, en}` | 四段内容的中英表述，用 `\n` 分段（构建器按换行渲染 `<br>`） |
| `verifiedAt` | 日期 | 实际核对日期 |
| `specs` | 对象 | 卡片规格表，键用「中文 / English」双语写法。必含 `证据位置 / evidence` 与 `复现状态 / reproduction`；其余只放**能在 `evidence` 的 quote 里找到出处的原文数字** |
| `seeAlso` | 数组 | 可选，跨站引用（learn 词条、tools 档案、models 指南），目标必须存在 |

## 禁止

不写「证明最强 / 全面超越」；不把摘要里的目标写成已达成的结论；不把作者推测写成事实；不用第三方博客替代原文；不因为翻译改写刷新 `last_verified`。方法谱系页只排时间与引用关系，不给质量排序。

新增条目走 `intake/<id>.json`，主流程合并进 `entries.json`。
