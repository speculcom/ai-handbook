NariQ: Sub-3-Bit Quantization for Long-Horizon Agentic TasksNariQ: Sub-3-Bit Quantization for Long-Horizon Agentic Tasks

问题：长程 Agent 任务要在 100K+ token 上下文里连续调用工具，但很多低比特量化只在短网页文本上校准、用困惑度验收；Qwen3.8-27B 已有的 ≤3-bit 量化在 AIME 这类短任务上能追平 BF16，在 DeepSWE 这类长程任务上最多只解出 BF16 的 72%。
证据位置：摘要提出 trellis-coded 训练后量化，校准数据来自 BF16 模型在 Agent 会话里生成的 token；Hugging Face 卡逐项给出：BF16 53.8GB / 3.0bpw 10.1GB / 2.5bpw 8.4GB / 2.0bpw 6.8GB；DeepSWE v1.1 为 39.8 / 41.0 / 41.9 / 28.6，Terminal-Bench 2.1 为 62.6 / 63.8 / 60.2 / 52.4，AIME 25+26 为 97.7 / 98.3 / 96.5 / 86.0。
作者自陈局限：2.0bpw 在 DeepSWE 低 7.3 分、AIME 低 11.7 分；只验证 Qwen3.8-27B 一个模型；多 token 预测模块尚未量化；llama.cpp fork 针对 SM120 调优，其他 GPU 变慢，Ampere 以前回退 CPU；KV cache 与激活尚未量化；更多模型、更多 Agent harness 与更多基准仍是未来工作。
它没主张的：不是所有模型都能无损压到 3-bit 以下；不是「2.0bpw 也能用」；不是 vLLM / 通用推理栈的即插即用方案；不是独立第三方复现；也不是 Nous 的模型。Problem: long-horizon agents call tools over many steps at 100K+ token contexts, yet many low-bit quantisation methods are calibrated on short web text and judged by perplexity. Existing ≤3-bit quantisations of Qwen3.8-27B match BF16 on short tasks such as AIME but solve at most 72% as many DeepSWE tasks as BF16.
Where the evidence sits: the abstract proposes a trellis-coded post-training quantisation calibrated on tokens generated by the BF16 model in agent sessions; the Hugging Face card reports BF16 53.8GB / 3.0bpw 10.1GB / 2.5bpw 8.4GB / 2.0bpw 6.8GB, with DeepSWE v1.1 at 39.8 / 41.0 / 41.9 / 28.6, Terminal-Bench 2.1 at 62.6 / 63.8 / 60.2 / 52.4 and AIME 25+26 at 97.7 / 98.3 / 96.5 / 86.0.
What the authors say about limits: 2.0bpw trails by 7.3 points on DeepSWE and 11.7 on AIME; only Qwen3.8-27B is tested; the multi-token prediction module is not quantised; the llama.cpp fork is tuned for SM120, runs slower on other GPUs and falls back to CPU before Ampere; KV cache and activations are not yet quantised; more models, harnesses and benchmarks remain future work.
What it does not claim: not every model can be losslessly compressed below 3 bits; not that 2.0bpw is usable; not a plug-in for vLLM or every inference stack; not an independent third-party reproduction; and not a Nous model.
